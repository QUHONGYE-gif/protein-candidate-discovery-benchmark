# M5D 第一阶段：特征消融与预测诊断开发结果

本结果属于 **ITERATION 开发证据**，不是新的独立外部确认。跟踪：Issue #104 / PR #105。
负责人在分析后明确授权使用这 9 个复合物进行开发；原正式结果保持冻结。

## 本轮决定：unstable / revise

六个新增特征/模型组合中，五个为 unstable，F1+XGBoost 为 negative，没有 positive。
本轮已完成固定比较并停止；不因局部改善自动扩量、调参或进入新的正式外部确认。

- F2 消除全部观测候选的表示碰撞，组级 MAE 相对 F0：RF 下降约9.3%，XGBoost下降约11.0%。
  预测Spearman也改善，但 RF 的探索召回变化 +1.1458pp、Greedy -1.8056pp；
  XGBoost 探索 -0.5556pp、Greedy +1.8750pp。平均预测改善未稳定转化为发现改善。
- F3+RF 探索总体 +2.1875pp，但四组分别 -5.00、0、+1.25、+12.50pp，收益集中于一个组；
  F3+XGBoost 的一组下降10pp。不能用总体小幅改善覆盖组间损害。
- F1 未减少本队列碰撞，且 XGBoost 主指标负向；不建议沿此方向扩大。
- F2/F3 的 sigma–绝对误差秩相关没有较 F0 增强；这里只描述相关，不宣布校准失败。

允许结论：位点表达改善了本开发队列的平均预测与部分发现结果，但尚无跨组稳定的
发现收益。禁止结论：探索机制被确认、新方法胜出或独立外部验证通过。

最多一个下一实验建议：固定 F2 与 XGBoost，另立小规模开发契约，检查均值/不确定性
尺度与目标对齐，并前瞻比较少量 beta（含 Greedy 的 beta=0 与原 beta=1）。
不同时增加特征、模型、批量或改换主指标。本次未执行该后续实验。
