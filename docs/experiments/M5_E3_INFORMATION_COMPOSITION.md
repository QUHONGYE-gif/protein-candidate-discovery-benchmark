# M5/E3：固定训练数量的信息组成对照

2026-09-10，执行前便笺，ITERATION / L1。用户批准在状态诊断后继续该原因干预。

原问题：固定策略下，什么训练信息条件影响预测改善转化为高值发现？
本单元检验“有限训练集中较高标签观测占比不足”这一具体解释，并用标签范围覆盖作竞争对照。
整体机制完成需要目标因素变化及其预测/收益响应；本单元有效但不明确也可停止。
Scope: ALIGNED / DIRECT。动作→操纵已观测训练集组成→测量高值区预测和G收益→收窄信息解释。
这不是新标签采集效率研究，也不把训练数量固定误称为所有可用信息完全相同。

## 固定设计

- 三项既有良性C：PABP/HSP82/HXK4；仅原XGB与421维组成+固定ESM1v输入；原十seed1729–1738。
- 每状态复用原64个预算内允许观测，剩余池统一排除这64个；每臂实际拟合恰好32个标签。
- `random`：原不看标签选出的32个初始样本；重新拟合并逐值重建原421维保存预测。
- `upper`：64个允许观测按标签升序、候选ID破同分，取后32个。
- `spread`：同一升序序列按round(linspace(0,63,32))的32个位置选取，覆盖已观测标签范围。
  round使用NumPy最近整数规则；同分保留ID顺序。它是范围对照，不保证增加方差或可学习信息。
- 三臂的选择器可收到相同64个允许观测；random规则忽略标签，其他两臂使用标签选择训练子集。
  两个干预都只选已付费观测，不用全任务真值、高值阈值或未观测标签作训练选择。
- 模型配置、拟合样本排序、可见特征、剩余池、初始最好值、G16规则和总80标签成本背景相同。
  64个标签用于选择/拟合，主批次16；不是只支付32个标签的算法。
- 每任务十个配对状态，总30状态、三臂90点拟合；接通为每任务原seed1729，共3状态/9拟合。
  无RF、UQ、探索E、匹配随机、超参搜索或新assay。接通与full不作为独立重复合并。

## 干预强度、端点与解释

先在模型worker中记录训练标签均值/标准差/范围/IQR、唯一标签数、已观测库上四分位占比、
训练子集重叠及420维几何最近距离。上四分位阈值只由允许64观测计算，非任务top1%真值阈值。
upper预期提高所选标签均值及较高标签占比，可能缩窄范围；spread预期涵盖库内两端。
这些只是可观测组成干预，不预称为信息增加或标签质量提高。

主比较：upper−random 的G16 top1% recall，报告命中数及配对区间；spread−random与
upper−spread为预列竞争诊断。高值定义及ties、分母378/133/86沿用原评估器。
预测诊断：剩余池rho/MAE/top1% AUC、真实近高值区AUC、首次/中位高值排序、前16构成；
三臂预测top64并集上的共同前端AUC另报，该集合由预测定义，不用真值筛选。
K8/32/64为固定预测的辅助截断，不算总成本80下的新主发现收益，不替换G16。
总池和近高值AUC改善不等于选点前端改善；共同前端缺高值时AUC未定义，不能补零或删状态求CI。

按assay分别分析10配对seed，20,000次99.375%描述性bootstrap，PCG64 seed12301。
两辅助对照与主对照共用抽样槽；不跨任务配对，不把状态当作独立assay；不创造应用delta。
若干预强度改变而高值区或收益未改善，只约束这些具体选择规则；不得排除所有训练信息原因。
即使收益改善，几何覆盖和标签分布仍可能共同变化，不能直接确认唯一上游机制。
若三者出现一致响应，形成进一步确认的条件性信号，仍不是独立生物数据或前瞻验证。

## 边界、预算和停止

复用现有服务器/解释器/缓存/helper，原数据和成功产物只读。Evaluator仅提供原64允许观测；
spawn worker不接收完整真值，保存三臂训练身份/配置/预测/选择后退出，评估器再评分。
进入评分前核验候选/观测/分母身份、训练数量、原预测精确重建和选择可重算。
执行前合成检查只检验选样边界、tie、计数和共享seed统计；不新增框架、依赖或完整审计。
Decision Guard采用已批准方向和原服务器资源边界内的小切片；比直接扩模型/标签/任务更可逆。

单worker/单线程；累计15分钟、进程树1.5GiB、全输出256MiB、紧凑回传5MiB、新费用0。
接通上限90秒；成功且剩余预算足够才运行full，full上限800秒。一次实现修正或瞬时重试
须保留原attempt且仍在累计上限内；科学身份/泄漏错误立即停止，不继续扩量。
无新湿实验或新的允许标签范围；正常重读原预算观测如实记为re-reveal，不称没有oracle读取。
不读取A/B/D、新assay、held-out或COS，不覆盖/晋升正式证据。

输出实际attempt、源码/输入/模型身份、紧凑结果、独立算术核验及科学限制后停止。
