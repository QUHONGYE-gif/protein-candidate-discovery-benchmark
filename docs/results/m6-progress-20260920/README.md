## 1. 筛选问题的后续验证

独立候选池实验完成4个既有assay×3个新池×5个新seed×3臂，共180条新轨迹。不同池排除重复ID和完全相同序列；这不是未见assay或独立蛋白家族泛化。

- 8个预列主比较均未满足严格跨池方向标准，原SPG1大幅收益不能外推为跨池稳定优势。
- CAPSD三个新池的top1%目标均在hard25外；全池均值相对hard25共10胜5平0负，三个池平均召回差为+20、+20、+26.7个百分点。前两池各3胜2平，未满足每池至少4胜的预定条件。
- GFP/P2取消筛选反而在5次配对中全部变差，hard25平均召回高46.7个百分点。
- 这些结果支持筛选可能有益也可能阻断目标，不能直接提供运行前的筛选风险预测器。本单元没有HF-only臂，也不能估计LF纯收益。

## 3. 动态释放：四轮已完成尝试

共同开发面板为CAPSD/P1与GFP/P2，各三个已见初始化seed。起点同16HF与全部256LF，后续45HF含核查与救回，实际费用6356。这里检验HF候选资格控制，不是完整LF/HF联合采购。

| 单元 | 新执行/旧引用 | 主对照差：CAPSD；GFP | 预定处置与可识别缺口 |
|---|---|---|---|
| 局部失配v1 | 36新轨迹 | [0,-1,0]；[0,0,0]，相对固定随机核查 | stop_v1。分组253/1/1/1，270次决策无救回触发；无法评价有效触发后的净收益 |
| 均衡分组与预算可达性v2 | 18新＋30旧引用 | [0,0,+1]；[0,0,0]，相对固定随机核查 | revise。42次救回、1次直接主命中；收益不能归给新增复杂控制 |
| 简单组合对照 | 12新＋42旧引用 | [0,0,0]；[0,0,0]，v2相对均衡分组＋固定核查 | stop_added_controller。简单组合37次救回，v2为42次，主结果相同；4条轨迹完全相同，2条仍有改选，非普遍等效 |
| 实测反例触发限额放行 | 12新轨迹 | [0,0,-1]；[0,0,0]，相对简单组合 | stop_current_version。30次核查仅2次触发、2次救回无直接主命中；额度未耗尽、无名额过期 |

三差顺序为3729/3730/3731，单位是新增top1%命中数。不同版本的对照不同，不能把各行相加或视为独立蛋白重复。预定停止决定与池内方向判定是两层：这些池内主方向均为inconclusive，停止并非统计显著负向。

最新限额版本在CAPSD/3731第三次新增购买出现首次分歧：两臂已购状态和RF均值一致，简单组合救回一个目标，新规则无名额并选择非目标。它定位了一次决策分支的阻断；此后两条轨迹共有37个购买位置不同（包括首次），终点差仍是整套策略效果，不能单独归给额度或过期规则。

辅助结果保留：最新版本top0.5%与主差相同，top2%为CAPSD[+1,0,-1]/GFP全零；CAPSD/3731最好值下降0.43834671955，其余五状态终点最好值相同。v2对固定随机核查的top2%为CAPSD[-1,0,+1]；简单组合与v2三阈值终点、最好值及四个预定费用前缀相同，但不代表所有时点相同。更少救回不等于更低总费用。

## 4. 购买前信息价值：已实现，但可靠性处理无新增收益

24个已见开发初始状态、70个去重查询、936次scorer；先锁定购买前预测与查询，再揭示标签，锁定后续8个候选后评价。各臂同q+8=9次新增HF、费用2756。三个事后训练重复在状态内平均。

- 可靠性规则相对普通配对估值改变7/24次选择，但24个主命中差全部为0，预定为stop_added_rule。
- 相对原均值选择为0胜22平2负，负向状态位于BLAT和SPG1。
- 三阈值命中相对普通配对均为零差，但两个状态最好值下降，因此不能说所有输出相同。
- 工作高斯分布、少数标签情景和训练重复均未获得校准保证；这里只覆盖一次采购加固定后续批次，不覆盖LF采购或长期政策。

[PRIMARY_RESULTS.json](PRIMARY_RESULTS.json)逐字段保留四轮释放与购买前估值的原主结果；没有用辅助正结果替换主终点。

## 5. 已完成与仍开放的问题

已完成的是问题诊断、可执行候选规则、同预算对照及上述停止决定。尚未建立的是：

1. 仅用当时可观察信息，可靠判断池外候选是否值得核查，以及核查能否提供足够决策信息。
2. 释放数量与机会成本的有效控制；尚不能证明增加规则优于已有简单组合。
3. 候选域调整与LF/HF采购的联合控制；当前释放实验已预购全部LF，不能充当该联合方法的结果。
4. 购买前价值估计中的可利用查询差异、估值误差与训练波动分别限制了多少收益。
5. 未见任务验证、真实实验闭环、湿实验效果，以及具体区别特征的现有技术对照。

这些是研究问题清单，不是已冻结的新实验方案，不授权改参、扩量、服务器使用或申请提交。当前停止版本不因清单而自动重启。
