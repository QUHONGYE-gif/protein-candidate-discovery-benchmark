# M5/E3：截断效应与收益估计精度

2026-09-10，ITERATION / L1。120个原配对状态的本地汇总分析已完成，独立算术复核通过；独立科学审核待完成。

## 结论

六个assay/model的直接对比均未建立“截断64与16的单位候选收益改善不同”。这修正了此前将较大截断有响应、主16不明确倾向解释为预算断点的说法；它不证明二者等价，也不证明收益不明确只是精度不足。

PABP/XGB的输入改进在16/32/64的每候选收益点估计为+2.188/+2.344/+2.109个百分点。64相对16的直接差为−0.078 [−4.375,+3.672]个百分点：既有“小幅收益”解释与现有数据相容，但仍容许有实际大小的正负截断差，不能确认固定比例收益。

HXK4/RF的初始量辅助交互为+2.969 [+0.156,+7.188]个百分点，提示合并两档初始量可能掩盖异质性。它是已见数据的辅助发现；原初始量也关联训练集合、标签组成及候选池，不能单独归因为标签数量或高值例数，不升级为跨任务机制。

## 核心直接对比

Δprecision是新输入减旧输入。D=Δprecision64−Δprecision16，单位均为**百分点**。下表等权平均初始32/64，但每次bootstrap同时移动同seed的两档状态；只有十个共享seed槽，不是20个独立样本。所有区间为20,000次99.375%描述性百分位区间。

| PABP/XGB | +2.188 [-1.250, +6.250] | +2.109 [+0.391, +4.062] | -0.078 [-4.375, +3.672] |

## 对原研究目标的意义

- 原输入干预改善全局预测仍成立；主G16收益不明确仍成立。本轮纠正解释，不改原终点或将辅助32/64提升为成功标准。
- 不能把所有不明确收益预先当成零，再寻找统一失效原因。现阶段存在收益大小、精度和任务/初始状态差异几个未分开的因素。局部高值排序可以是限制环节，唯一上游根因仍未识别。
- 当前先停止同类模型微调。条件性下一单元是补足A/B固定策略、同状态的受控预测比较：先具体化只允许候选池的评估入口及输入对照，再在既有任务上检验“全局改善是否到达发现相关区域”。这不是本轮新增执行或数据访问授权。
- 暂不以增加seed直到区间不含零或扩展新assay作为成功路径；若以后需要增加数据，应根据要区分的效应与新学习条件预先设计。D保持既有汇总范围，联合M5与独立确认尚未完成。

## 有效性与限制

1. 本轮SHA绑定原汇总，只复用其中已评分的计数；核验120状态、3600计数/分母关系和新旧剩余池计数。没有候选级ID或真值可用于重新选点。沿用原输入单元的身份/标签核验，不冒称重新审查了全部原始数据或OS强隔离。
2. 固定预测的K截断不是带新标签反馈的预算实验；各K内部新旧候选池一致，跨K实际测量成本会增加。无实际采集效率或长期学习收益结论。
3. 只有三项已见良性任务与十seed，重复开发、多重诊断、离散/退化bootstrap限制保留。没有应用收益阈值，不把区间外范围称为绝对不可能，不将辅助交互当作独立验证。
