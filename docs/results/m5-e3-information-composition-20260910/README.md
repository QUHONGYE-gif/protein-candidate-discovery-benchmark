# M5/E3：固定训练数的信息组成对照

2026-09-10，ITERATION / L1。第2阶段主体、第3阶段核验完成，第4阶段仓库整理。
对应[执行前便笺](../../experiments/M5_E3_INFORMATION_COMPOSITION.md)。

**提高已观测训练标签的高分占比，并未建立主G16 top1%召回改善，且三项任务的全池排序下降。
范围覆盖配方也未建立稳定的高值预测或主召回收益。两个配方仍不能识别唯一原因。**
同时存在PABP辅助K8命中、HXK4辅助K32命中及G16最好值的正向描述信号，全部保留，
不能笼统概括为所有收益均无改善。整体M5机制目标仍未完成。

## 实验做了什么

三项既有良性C、原XGB、421维输入、原10个seed。每个状态共享原64个允许观测；
三臂都拟合32条，剩余候选池统一排除64条，主批次固定贪心16，总标签成本背景80。

| 配方 | 从同一64条已观测标签中选32条 | 检验目的 |
|---|---|---|
| random | 原先不看标签选出的初始32条 | 原基线，点预测逐值精确重建 |
| upper | 按已观测标签排序，取较高的一半 | 增加较高标签占比，但会同时改变范围和样本组成 |
| spread | 按已观测标签秩等间隔取32条，包括两端 | 提供覆盖已观测标签范围的竞争配方 |

“较高”相对于这64条已观测标签，不等于真实任务top1%。三臂选择器可获得同样的64标签，
但random规则忽略标签；这不是只支付32标签的采集算法，也不表示三臂实际使用了相同信息。
没有改变模型、特征、贪心规则、阈值或主预算，没有探索E或UQ实验。

## 干预是否实际发生

上四分位阈值仅由已允许64观测计算。下表为每任务10状态的臂均值，标签范围保留任务原量纲，
不同任务不合并。upper相对random的占比/均值增加，以及spread相对random的范围增加，
对应描述性区间均排除零。

| 任务 | 已观测库上四分位占比 random / upper / spread | 标签范围 random / upper / spread |
|---|---:|---:|
| PABP | 26.56% / 50% / 25% | 1.245 / 0.762 / 1.292 |
| HSP82 | 22.81% / 50% / 25% | 1.554 / 0.587 / 1.781 |
| HXK4 | 24.06% / 50% / 25% | 2.733 / 2.668 / 3.855 |

upper相对random的标签均值变化依次为+0.323、+0.280、+0.635。PABP/HSP82的范围明显
收缩，HXK4该范围差的区间含零。几何距离变化较小且区间含零，不能认定几何因素等价。
改变这些统计量不等于增加可学习信息；样本身份、标签分布和功能/特征覆盖都可能共同变化。

## 预测如何响应

下表为upper−random，每任务10个配对seed；20,000次99.375%描述性bootstrap，seed12301。
重复开发和多指标选择没有被这一名义覆盖率校正。

| 任务 | 全池rho变化及区间 | 全池top1% AUC变化及区间 | 真实近高值区AUC变化及区间 |
|---|---:|---:|---:|
| PABP | −0.214 [−0.346,−0.106] | −0.042 [−0.096,+0.012] | −0.004 [−0.022,+0.016] |
| HSP82 | −0.284 [−0.397,−0.160] | −0.033 [−0.081,+0.016] | −0.064 [−0.119,−0.013] |
| HXK4 | −0.314 [−0.435,−0.212] | −0.019 [−0.070,+0.030] | +0.029 [−0.031,+0.100] |

upper在三任务的全池排序都下降，未建立高值AUC改善。spread−random的全池rho、top1% AUC
区间均含零；HSP82真实近高值区AUC还下降−0.035 [−0.061,−0.003]。
三臂训练rho仍约0.9996–1，不能把结果解释成训练总体排序未拟合。

真实近高值区是top1%与top2%去除top1%的比较，不等于实际决策前端。
另在三臂预测top64并集上计算共同前端AUC，该集合只由预测确定。PABP有10/10状态可定义，
三对照区间均含零；HSP82和HXK4分别只有8/10、9/10，缺高值状态保留，未补零或按可定义
子集求CI。它们不能据此判为有或无前端改善。

G16最好值使用共同64观测的初始最好值，是实际主预算下的辅助效用，不能归为超预算K32。
它保留任务标签原量纲，不能与其他assay数值直接比较。K8/32只是同一固定预测的截断，

PABP K8和HXK4 K32的upper−spread直接对照区间都含零，不能通过与random各自显著性不同
推断upper优于spread。最好值的HXK4直接对照如表，仍仅为本开发样本信号。

这些是训练配方变化后的收益信号。upper的整体预测反而下降，高值AUC未建立改善；
因此不能当作“预测变准带来发现增益”的确认，也不是探索策略优势。辅助信号需先复现，
不据此换主预算、选阈值、扩量或宣称已找到机制。

## 能回答与不能回答的原因问题

本实验使原本描述性的“训练组成可能重要”变成了一个实际配方干预：增加已观测库中较高
标签占比，并没有自动改善高值区预测和主召回，反而损伤全池排序。仅覆盖标签两端的
另一配方也没有给出稳定改善。保留较多普通/较低标签可能影响总体排序学习，但当前设计
不能把这个影响独立归因于标签范围，更不能确定它解释原输入干预的收益不稳定。

upper同时改变占比、均值、范围/IQR、样本身份与特征组成；spread也不是只改变范围。
这不是两个因素的正交设计，不能把三臂差异分解成各因素的独立因果贡献。没有保证任务
真正top1%观测足够，也没有直接改善局部高值信息，故不能排除极端高值稀疏、表示、噪声
或其他训练信息原因。不能把未建立收益预设为零，再声称已经解释零收益。

下一方向应区分“配方确实改变高值判别信息”与“只改变标签分布”，并先确定能验证这点的
对照；当前不自动增加assay/标签/seed或继续调配方求阳性。A/B受控同状态比较、独立数据
确认、多轮收益及整体M5机制目标仍未完成。D本轮没有新执行或数据访问。
