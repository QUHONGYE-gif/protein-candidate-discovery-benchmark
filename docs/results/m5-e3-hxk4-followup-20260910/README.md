## 2. 哪个选点前端环节有响应

每状态冻结两模型全池预测，分别构造预测前64池，再交叉用两模型排序取16。所有池和
选择均不使用真实标签，四组合总标签成本均80。XX与RR精确等价于原两臂贪心16。
下表是新40状态的平均高值命中数，完整区间见全部端点：

| 预测前64候选池 | 用XGB排序取16 | 用ridge排序取16 |
|---|---:|---:|
| XGB池 | XX=0.35 | XR=0.60 |
| ridge池 | RX=0.45 | RR=0.825 |

固定ridge池时，改用ridge排序的条件差 **RR−RX=+.375[+.025,+.775]**；固定XGB池时
相应差XR−XX=+.25[−.10,+.70]。这支持“在本次ridge产生的前64池内，排序替换有正向
发现响应”的开发期诊断。它不是near/global AUC改善、整个流程稳定胜出或唯一因果机制。

采用两种操作顺序的对称平均分解：

| 分量 | 新40均值与区间 | 旧20本轮描述 |
|---|---|---|
| 池替换 | +.1625[−.1125,+.475] | +.525[+.06242,+1.175] |
| 池内重排 | +.3125[+.0375,+.650] | +.325[−.125,+.800] |
| 合计 | +.475 | +.850 |

逐状态分量之和严格等于RR−XX。原四格、四条条件差和交互均保留；新交互+.125
[−.35,+.60]。**不能由一项区间排除零、另一项含零推出重排贡献大于池替换**，也不能按
点估计比率给出已确认机制贡献率。旧新哪个分量区间含零不同，不证明机制发生反转。
条件差RR−RX与对称重排分量共享同一四格和状态，属于相关辅助端点，不是两次独立复证；
本轮没有对全部端点作同时推断。
两种前64池的高值数量均值2.025/2.075，差+.05[−1.375,+1.525]；不能证明相等或无池效应。
分解依赖预列K64及已有两套预测，不能直接回答正则化、线性假设或训练信息为何改变分数。

两G16集合平均只重叠1.525个候选；共同命中均值.05。ridge独有命中在XGB的排名
17–64/65–256/>256三档分别为.225/.05/.50，XGB独有命中在ridge对应三档为.05/.15/.10。
这是各类命中的账目分解，不能仅凭“原排得很后”确认泛化机制。
共同top64并集AUC仅33/40状态可定义，未删除7个状态后计算总体区间。
