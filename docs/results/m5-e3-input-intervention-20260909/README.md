# M5/E3：固定策略的预测输入干预

2026-09-09。三项良性C任务的首个执行单元完成主体实验及聚合复核，进入仓库整理。
证据身份为ITERATION / L1；独立科学审核待完成，联合A/B/C/D及M5整体未完成。

**本次确实改善了预测，但尚未建立明确的发现收益增益。**六个assay/model单元的Spearman、
top1% AUC均提高，MAE均下降，对应99.375%描述性区间均位于改善方向。固定Greedy的六个
发现收益差区间均包含零（GCK/XGBoost上界恰为零）；不能解释为证明没有收益或实用等价。

## 对照和主要结果

只将原420维组成输入改为420维加固定公开ESM1v_single分数。沿用原候选池、32/64嵌套初始
观测、10个seed、RF/XGBoost配置、每批16和64个精确重叠匹配随机分支。所有120状态均保留。
G按均值，RF的E按不确定性，XGBoost的E按均值加不确定性；不同模型分别报告。
这是固定学习器和策略的输入干预，不能称为只操纵了抽象的“预测准确度”这一个标量。

下表主发现指标为top1% recall增量，单位为百分点；区间反映assay内共享seed变异。

同一顺序的固定E平均命中变化为-0.20、+0.25、+0.05、-0.15、-0.10、-0.20，六个区间也均
包含零。各自E−G/E−M、预测变化区间、top0.5%/2%与best-found敏感性均保留于
[analysis.json](analysis.json)。不以探索相对优势是否扩大替代固定策略的绝对收益比较。

## 本次对原因分析增加了什么

- 输入干预成功改变了目标中间指标：此前位置表示没有明确改善高值AUC，这次整体预测及
  高值AUC均改善。因此“干预完全没有改善预测”不能单独解释本次尚未建立发现增益的结果。
- 高值AUC的改善也不自动保证前16名的命中增加。AUC比较的是大量高值/非高值候选对，
  极少数实际选点更依赖最前沿的局部排序。这一指标与决策的差别与结果相容，但不是唯一根因证明。
- 进入/退出集合的净命中变化逐状态精确等于新旧发现差，定位了收益来自哪些集合的更替；
  这仍是算术分解，不能独立解释为什么那些候选被预测到前沿。

仍未排除：高值极稀疏与初始化覆盖限制、预测前沿的局部误差、收益区间不精确、以及不同
assay的学习难度。输入变化同时可能改变均值与不确定性，固定E的变化不能独立归因于其中之一。
本轮没有训练覆盖干预、均值/不确定性拆分或多轮长期收益实验。条件性下一步最多提出一个
保存预测的均值/不确定性拆分对照，不在本轮自动启动，也不能替代前沿预测误差的证据。

判定：**预测干预有效；发现增益仍不明确；继续解释需收窄假设。**完成固定矩阵后停止，
没有按结果增加任务、seed、阈值或参数。原E3问题已有更直接的初步证据，原因目标尚未全部完成。

## 即时有效性和统计核对

候选、分数、标签源及原预测文件的身份在运行中核验。原允许观测及bootstrap抽样保持相同；
workers仅接收无标签特征和允许观测，完整真值由评估器加载，拟合/选择保存后才进行全池诊断。
分数提取的样本行顺序与标签列不变性通过合成检查。这是代码/进程分离，不宣称OS强隔离。

原基线所有分支由已保存预测重建，120状态配对通过；6个smoke状态与full对应聚合逐项相同。
本地仅用聚合结果独立复核47,520项新旧分支count/recall、进入/退出净收益、全部固定策略区间
和预测变化区间。无候选级文件或真值回传；不把聚合复核称为独立重读原始标签。

每模型按共享seed槽重采样，先保留32/64依赖，20,000次、99.375%描述性百分位区间。
辅助E−M在每次选中的状态内部再重采样64个匹配随机重复。该辅助实现采用记录在源码中的
PCG64流，保持统计层次，但不是历史C使用的SHA随机流或历史四单元合并结果，不能宣称字节复现。
独立生物单位仍是三个assay；没有跨任务总体区间，没有按seed数扩张独立样本量，也没有应用delta。
