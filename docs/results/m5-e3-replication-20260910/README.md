# M5/E3：新初始状态的复现与任务迁移

2026-09-10，ITERATION / L1。本轮第1–3阶段完成，结果与代码同步；独立科学审核待完成。对应[执行前便笺](../../experiments/M5_E3_REPLICATION.md)。

## 结论

**预测指标改善在三个任务的新初始状态上重现；原PABP/XGB的top32/64发现收益正向信号未达到本次预定复现标准，向HSP82/HXK4的收益迁移也未建立。**

三个任务、初始32/64的六格均有Spearman和top1% AUC正向区间、MAE负向区间，说明相同输入干预在这些新状态中仍改善预测。但全部发现命中变化区间包含或触及零，包括预定的32和64。PABP新seed合并效应在32为−0.100 [−0.450,+0.225]个命中，64为+0.025 [−0.625,+0.663]。

这限制了旧阳性案例的稳定性解释，不证明旧结果虚假、不证明真实收益为零，也不把新旧“显著/不显著”差别当成已经检验过的批次交互。旧结果完整保留，旧、新seed没有合并来补强阳性。

## 实验过程

- 沿用PABP/HSP82/HXK4三个既有良性candidate-pool、原XGBoost全参数和原420维组成→加一列ESM1v_single的输入对照；贪心规则固定，排序前8/16/32/64全部保存。原主G16不变，本次复现问题预先同时指定32与64。
- 先用旧seed1729和初始32/64，共6状态重建。两臂12份点预测逐值等于保存快照，180个旧指标端点重新吻合；这完成实现复现，不是新科学证据。
- Full使用预先固定的新seed2000–2019，每任务20个seed×初始32/64，共120配对状态、240个点拟合。新seed只改变不看标签的初始抽样，XGBoost内部random_state仍为1729。
- 每状态两臂同样本/观测/剩余池，不改为共同排除64；初始32是64的前缀。数据来源不变，但为新的模拟初始状态揭示了预算内的历史标签；没有新湿实验测量。
- 模型worker只收到可观测特征和该状态允许观测；全部预测/选择保存、worker退出后评估器评分。完整真值不作为worker参数，代码/进程分离不声明OS强隔离。
- 新状态独立于旧seed选择，但训练子集可能重叠且使用同一测量数据，不能称独立新数据验证。HSP82/HXK4也已参与开发，本轮是已有任务上的迁移复测。
