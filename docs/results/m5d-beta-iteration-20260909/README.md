原正式结果与第一阶段产物保持只读；本开发队列不能重新作为独立外部确认。

## 本轮决定：unstable / revise

五个beta中，0/0.25/0.5为unstable，1/2为negative，没有positive。
已完成固定比较并停止；不加密beta网格、不进入多轮训练或新外部确认。

- beta=0.25/0.5相对Greedy分别+0.8333/+0.8681pp，相对原beta=1为+3.4375/+3.4722pp。
  beta=0.5对原beta=1只有两个组严格正向，另外两个为零，未达到预声明至少三组改善。
  相对Greedy的四组差为-1.6667、+5.0000、+0.1389、0pp；仍存在组间权衡。
- beta=1/2相对Greedy分别-2.6042/-4.2708pp；这支持在本开发队列中减弱探索权重，
  不支持沿更强探索方向扩大。两个弱探索beta的差距很小，不能据此确定0.5为最优。
- std(sigma)/std(mu)的组级平均约0.425，sigma与绝对误差Spearman约0.145。
  beta从0.5增至2时，每批相对Greedy置换数由2.18增至6.04，所选真实均值下降，
  所选MAE上升。该模式与探索重排更多低质量候选一致，但不单凭这些相关性确认机制。
- mean(sigma)/MAE约0.487仅是尺度诊断；bootstrap标准差与绝对误差不是同一统计量，
  不能将此比例直接解释成概率校准失败，也不能使用隐藏残余标签拟合缩放系数。

建议停止扩大beta搜索。最多一个下一实验：固定F2＋XGBoost，仅用初始已揭示观测
构造交叉拟合残差，诊断原bootstrap sigma的误差排序能力；残余池标签只在评价侧使用。
该实验尚未实施，不预设新的不确定性方法一定改善发现。
