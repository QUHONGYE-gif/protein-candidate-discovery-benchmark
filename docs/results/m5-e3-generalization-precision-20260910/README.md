# M5/E3：学习方法泛化与状态估计波动

2026-09-10，ITERATION/L1。第二、第三条原因研究的本次有界执行与算术核验完成。
[执行前便笺](../../experiments/M5_E3_GENERALIZATION_PRECISION.md)。

**同观测学习方法对照产生了条件性新证据：PABP近高值区区分改善但主召回仍不明确；
HXK4/64主召回改善但当前高值预测诊断未建立改善。状态子集诊断量化了已有目录的波动，
不能把全部不稳定归结为状态数不足。整体机制尚未闭合。**

两部分回答不同估计对象：学习实验比较ridge−XGB；子集诊断分析既有XGB新输入−旧输入。
后者不能替代对本次ridge收益的复现或机制检验。所有任务均已用于开发，没有独立新数据。

## 第二条：同信息、不同学习方法

复用原复测seed2000–2019，三项既有良性C，初始32/64，共120配对状态。每状态两臂共享
样本ID、允许标签、421维输入、剩余池、初始最好值、贪心16和高值定义。初始32对应48个
总标签，初始64对应80个；两档分开报告，合并只作同seed等权辅助。

对照是原XGB；干预是固定ridge配方：仅用训练观测估计输入均值/总体标准差，零方差列
除数置1，截距不惩罚，目标为mean squared error + ||β||²，即sum形式alpha=n_train。
NumPy双空间求解，不做调参或CV择优。每状态重新拟合XGB并逐值重建历史保存预测。
干预同时改变线性假设、正则化与标准化，结论归属于整个学习配方，不能单独归因其中一项。

主中间诊断为真实top1%与次1%的near AUC，主收益为G16 top1%召回。下表用命中差表达
同一主收益；除以任务原分母378/133/86即召回差。每格20配对seed，20000次99.375%
描述性bootstrap，seed12901。多次开发选择未由名义覆盖率校正；没有应用delta。

PABP两档near AUC的描述区间都为正，但绝对值仅约0.524，且主召回区间仍含零。
它提供“这一局部区分指标可以被学习方法改变”的证据，不是证明收益不会响应。
所有六格全池rho均下降，PABP MAE也增大，不能把ridge称作总体更准确的预测器。
HSP82两档top1% AUC和near AUC下降；32档near的区间上端极接近零，保留这一精度限制。

HXK4/64是本次预列主终点的正向开发信号：固定80标签成本下，平均命中从0.25到1.10，
召回增加约0.988个百分点。初始32不明确；不能据不同显著性状态确认初始量交互或标签量原因。
两档等权合并ΔG16为+0.70 [+0.025,+1.725]，仍只有20共享seed槽，不是40独立重复，
也不是某一个统一成本的实验。这些尚未在未参与开发的状态或独立数据上确认。

## 预测前端与辅助效用

真实near区并不等于实际选点前端。共同前端取两臂预测top64并集，只由预测确定。
PABP/32、PABP/64、HSP82/32、HSP82/64、HXK4/32、HXK4/64分别只有17/20、20/20、
14/20、14/20、17/20、17/20状态可定义AUC。唯一完整的PABP/64变化为+0.08716
[−0.07118,+0.24200]，不明确；其余及受影响的合并项不按可定义子集求CI，共8项缺失汇总。
因此HXK4的收益不能直接归因于已经证实的前端AUC改善。

全部辅助端点在[完整对照表](generalization-table.md)中，未隐藏阴性。除主终点外，
区间排除零的正向收益只有：HXK4/64的K8命中+0.65 [+0.20,+1.25]、K32命中+1.30
[+0.15,+2.75]、G16最好值+0.48752 [+0.02766,+1.05063]；HXK4合并K8为+0.45
[+0.05,+1.05]、K32为+1.05 [+0.175,+2.46258]。各K64命中差区间都含零。
G16最好值属于实际对应预算下的辅助效用，保持任务原量纲；K8/32/64只是固定排序截断，
不构成标签反馈、多轮收益或同80成本的所有K比较。没有新的探索E/UQ结论。

XGB训练rho约0.9997–1，ridge约0.9746–0.9900，训练拟合有所减弱而泛化响应按任务不同。
该现象不能单独证明XGB过拟合，也不能说明训练信息已经充足。PABP局部指标改善与HXK4
收益改善出现在不同条件下，不能拼成一条已验证的“局部改善导致收益”机制链。

## 第三条：状态子集能让估计波动多大

本部分仅使用此前180状态汇总，分析原XGB输入干预。旧10seed与复测20seed分开，
每个assay内的32/64同seed等权合并形成20个复测block。逐一枚举全部5/10/15个block
子集，分别15504、184756、15504种，未按结果挑选。完整分层见[子集表](state-subsets-table.md)。

下表为G16平均命中增量的**中间95%有限子集范围，不是总体置信区间**：

| 任务 | 20个已观察block均值 | 选5个的范围 | 选10个的范围 | 选15个的范围 | 选10个时均值为正的比例 |
|---|---:|---:|---:|---:|---:|
| PABP | −0.025 | [−0.50,+0.40] | [−0.30,+0.25] | [−0.1667,+0.1333] | 35.91% |
| HSP82 | +0.075 | [−0.10,+0.30] | [−0.05,+0.20] | [0,+0.1333] | 73.61% |
| HXK4 | +0.025 | [−0.40,+0.60] | [−0.25,+0.30] | [−0.1667,+0.1667] | 50.00% |

这量化了已观察目录中取不同状态子集时，估计大小和符号确实可能变化。原始复测40状态中，
两输入臂G16均无命中的状态分别为20、28、24；这是稀疏计数事实，不是因果贡献率。
范围随子集增大而缩小符合有限抽样方差恒等式s²(1/n−1/20)，不能当成新增独立证据，
也不能推算未来总体研究只需多少seed便会获得显著结果。

PABP较大截断还有一项精确的有限集合事实。**下表仅针对每seed初始32/64效应等权合并**：

| 端点 | 旧10seed的均值 | 从新20seed任取10个的全部最小/最大 | 达到旧均值的子集数 |
|---|---:|---:|---:|
| K16 | +0.35 | [−0.50,+0.45] | 388 / 184756（0.2100%） |
| K32 | +0.75 | [−0.50,+0.30] | 0 / 184756 |
| K64 | +1.35 | [−0.80,+0.85] | 0 / 184756 |

所以，仅在这20个已观察的合并block中重新挑十个，不能恢复旧合并K32/K64的均值；这一结论比泛称
“抽哪十个都会差很多”更具体。但零次不是总体p值或零复现概率：新20个状态未必覆盖
未观测尾部，旧新数据本就参与过开发。不能据此排除同一总体的抽样波动、确认系统性
批次机制，或声称初始样本量问题已经解决。仍没有识别测量噪声与状态组成各自的贡献。

分初始量的结论不同：K32的子集最大值在32/64两档分别为+0.40/+0.80，K64均为+1.20。
初始64、K32可以达到其旧均值+0.80，不能把合并目录的“不可能恢复”扩大到每个初始量。
全部分层及达到旧均值的计数均保留在子集表中。

## 当前两条解释推进到哪里

- 学习方法：同观测下局部判别和实际主收益都出现了可改变的条件，但尚未在同一条件中
  建立完整响应链。不能称普遍学习方法受限、唯一正则化机制或已排除训练信息原因。
- 稀疏命中/状态差异：已把“可能不精确”推进为有限目录的数值范围；它能描述部分符号
  敏感性，不能给出不稳定原因的解释百分比，也不能据此自动增加seed。

下一项条件性工作可优先检验HXK4/64主收益的重复性，并用完整可定义的前端诊断核对收益
响应；须预先固定对照与范围，不能因看见阳性不断追加。本单元未执行下一项。M5机制、
A/B受控同状态比较、独立assay确认及多轮推广仍未完成，D保持既有汇总范围。
