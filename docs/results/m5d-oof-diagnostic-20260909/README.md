# M5D 第三阶段：初始观测 OOF 不确定性诊断

本轮为ITERATION诊断，关联Issue #104 / PR #105。只在129.28.97.247执行，
只用初始已揭示观测进行四折交叉拟合；没有调beta、校准、采集新候选或访问新外部确认集。
固定F2＋XGBoost；每折1个点模型＋5个bootstrap成员，保存成员预测并以std(ddof=0)得到sigma。
每个初始观测恰有一次OOF预测；每折模型只收到该折训练观测。

## 原因分析与本轮决定

判定为 **unstable / revise**，主要未满足总体OOF rho>=0.20；其他条件均满足。
所有状态与折的sigma–误差相关均有定义，sigma没有全零退化。四组rho均正，富集总体1.2584，
因此sigma包含误差信息，但排序强度不足以达到本轮开发阈值。

1. OOF rho=0.1397、折内rho=0.1442，弱正相关在折内也存在，未见仅靠折间拼接形成
   强相关的现象。这与原剩余池约0.145的弱相关方向一致；训练量和评价对象不同，
   数值接近不能当成等价性检验。
2. 最高sigma四分位的误差约为均匀选择期望的1.258倍，能粗略富集难预测样本；
   但难预测不等于高价值。误差排序信息不能直接证明UCB会改善top1发现，第二阶段
   已观察到增大beta总体变差，不能把本轮富集当成推翻该结果的证据。
3. 点预测也存在组间差异：3BT1_A_U的OOF预测–真值rho=0.0525，1A22_A_B为0.0026；
   六复合物组为0.4940，1JTG_A_B为0.5316。两个弱组的均值预测排序仍需关注，
   本轮不能将所有发现问题归因于sigma。
4. 对sigma乘正的常数不会改变其秩相关；该缩放只改变它在mu+beta*sigma中的权重，
   等价于调整beta。因此不建议用全局放大sigma或继续加密beta搜索解决排序不足。
   mean(sigma)/MAE约0.471是不同统计量的比值，不证明概率校准失败。

已完成固定诊断并停止。最多一个下一实验建议：复用本轮OOF记录，按每折训练观测
是否覆盖留出候选的突变位点进行可观测覆盖度分层，比较均值误差及sigma排序；
检验两个弱组是否主要受未见位点影响。这是待验证假设，尚未实施，不预设新特征或模型。

## 预声明判定与全部结果

本轮判定 **unstable / revise**。

比较基准为无误差排序rho=0和均匀选择的期望富集=1。最高sigma四分位富集等于其MAE/
全部OOF样本MAE；先逐状态求比值再汇总，不能用聚合MAE重新求比值。
恒定sigma或零分母返回null。相关采用并列平均秩。
先平均复合物内种子及初始量，再平均组内复合物，最后四组等权。
折内rho为每状态四折的有效rho平均；不是将所有种子作为独立样本拼接。
