# Triage Labels

| Canonical role    | GitHub label       | Meaning                                  |
| ----------------- | ------------------ | ---------------------------------------- |
| `needs-triage`    | `needs-triage`     | Maintainer evaluation is required        |
| `needs-info`      | `needs-info`       | Waiting for additional information       |
| `ready-for-agent` | `ready-for-agent`  | Fully specified and ready for an agent    |
| `ready-for-human` | `ready-for-human`  | Requires human judgment or implementation |
| `wontfix`         | `wontfix`          | Will not be actioned                      |

Use the GitHub label in the second column whenever an engineering skill refers to the canonical
role. Do not create synonyms or duplicate lifecycle labels.
