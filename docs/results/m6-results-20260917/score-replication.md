# Proposed claim

In the four previously used 256-candidate development assays, fixed C0 proxy draws, unchanged RF/cost/budget/policy rules and five new initialization/bootstrap/tie seeds, removing the incumbent floor did not establish improved top-1% discovery at budget6400. The prospectively specified per-assay rule gives BLAT unstable (mean B−A0), CAPSD negative (−0.4;5/5 losses), GFP negative (−0.4;4/5 losses), SPG1 unstable (−0.2). These are descriptive paired-seed criteria, not significance tests or independent assay replicates.

The conditional numerical mechanism replicates: of80 prespecified nested A states,47 have zero A values with both examined fantasy maxima below incumbent; B has nonzero values and chooses LF in80/80. This diagnoses the current RF/finite-three-point approximation, not true information value. B buys all256 LF in20/20 trajectories and usually chooses HF other than the predictive-mean leader. This behavior does not imply discovery benefit, selective LF advantage, or pure LF causal effect.

The earlier two-seed BLAT positive direction remains historical but is not stably replicated on five new initialization seeds. CAPSD is negative at all three threshold sensitivities; GFP does not pass the negative direction rule at all thresholds. Post hoc truncation to the61st HF retains CAPSD/GFP negative directions: endpoint loss is not solely due to A's extra final1–2HF purchases. This is descriptive truncation, not a fixed-state intervention.

This does not validate B as a default replacement, establish a unified M6/M5 cause, prove LF generally useless, establish A superiority over HF-only, or resolve E5. New initialization replication uses old LF draws and known assays; no unseen/held-out validation or promotion. Remaining explanations include the HF information objective, surrogate/uncertainty/three-point approximation, and task/upper-tail proxy/cost interactions. No new experiment automatically launches.
