# M5/E3：分开部分标签组成变化后，主发现收益仍未明确

2026-09-11，ITERATION/L1。第2阶段主体实验与第3阶段算术核验完成。
本单元处理上一轮“同位点支持和训练标签组成一起变化”的混淆，整体M5机制尚未完成。

两个互补对照均完成：标签非常接近时增加支持，以及参考前沿支持严格固定时调整标签组成。
前者未建立高值区分或主收益；后者使ridge的全局MAE改善、near AUC反而下降，主收益仍不明确。
已有ridge固定池排名前移的辅助信号在部分标签匹配后仍在，但不能据此排除剩余标签组成或
其他输入信息，更不能把它变成纯覆盖因果效应。全部预测使用真实候选与真实允许标签。

## 执行前设计

[固定便笺](../../experiments/M5_E3_LABEL_BALANCED_SUPPORT.md)记录全部规则与停止条件。
既有公开良性HXK4、seed3000–3039共40状态、每状态64允许观测、421输入、原XGB和ridgeλ1。
每臂32条直接训练、排除完整64观测、共同剩余8506候选，主策略固定贪心16；
top1%召回分母86，成本背景80。参考前64来自原64标签ridge预测，带有间接允许信息，
不能叫32标签采集效率。没有新标签、状态、assay、模型族、依赖、D、held-out或COS。

支持对照：64允许标签排序后相邻配成32对，每臂每对选1条。差超过原64标签SD的.05时，
两臂固定选同一条；其余允许交换。从同一hash默认选择出发，分别局部最大/最小化参考前64
截断同位点支持数。严格改进、确定性tie、最多128次整数目标改变；不是全局最优声明。
两臂排序标签最大差被设计容差约束；.05是标签平衡容差，不是应用收益阈值。

组成对照：固定原support32中所有支持参考前64位点的anchors，只从参考池未涉及位点的
允许观测填充。动态规划选择32个真实观测，使其排序标签尽量接近原random32；强制anchors，
原support32始终是可行解。前64逐候选同位点计数和相关局部标签范围保持相同；
完整剩余池的支持及其他输入组成并不固定。匹配距离为排序标签平方差之和/(32×原64方差)。

两组主比较为pair_high−pair_low、composition_matched−original_support，各模型单独报告。
原support重新拟合并逐值重建旧预测，原random使用身份绑定的保存预测；其历史对比不作新复现。
composition_matched−original_random仅为预列辅助，不能称完整二因素析因分解。

命中差除以86就是召回差。四个主区间均含零，没有应用δ，不证明零效应、等价或非劣。

[−.01111,.00350]，near −.00580[−.01402,.00123]。更多同位点计数本身不等于更多有效功能信息。

组成对照中ridge MAE降低−.01895[−.02781,−.01062]，near AUC却下降−.01494
[−.03030,−.00236]；top1 AUC−.01058[−.02340,.00041]不明确。全局误差与高值附近区分
出现方向不同的响应，但主收益仍未明确变化，不能据此确认near AUC是唯一收益原因。
ridge最好值变化−.12385[−.37408,0]触零，不能称明确损失；所有辅助端点均保留。

## 固定池辅助信号：改善没有自动传到完整候选池

组成对照的XGB在原ridge固定池里G16命中.650→.825，差+.175[.025,.400]；
高值排名和64.40→59.15，差−5.25[−11.200,−.325]，表示该参考池内整体向前。
同一比较的完整池主命中为−.050[−.400,.225]。这是条件性固定池响应，不能把辅助池
当成可部署的新策略或用它替换主池；参考池选择、池外排序和候选进入前端仍可能影响结果。
相对原random，XGB匹配后的固定池命中差+.275[.025,.600]也是相关辅助量，不是独立确认。

ridge的组成调整对固定池排名和变化+.20[−4.225,4.925]，其相对原random的排名和
差仍为−23.25[−56.025,−1.937]；旧support−random为−23.45，后者只是历史重建。
这说明部分拉回标签组成后，辅助前移信号仍可观察到；不能推断标签组成已经无关，
因为匹配残差、anchors及其标签尾部仍保留，两个新对照的支持水平/训练身份也不同。

固定参考池AUC仅26/40状态有定义，14个无高值池未删除。五预测前沿并集AUC的定义数
XGB为37/40、ridge为35/40；不填零或只取完整案例算总体区间。
排名和受各状态高值数量影响，与命中共享排序和真值，不当独立中介证据。
