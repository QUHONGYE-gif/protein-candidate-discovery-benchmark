# M5/E3：正则化改变了排序，但尚未建立高值收益响应

2026-09-11，ITERATION/L1，第2阶段实验和第3阶段算术核验完成。
本有界单元完成不等于整体M5原因目标完成；属于已有景观上的开发干预。

在同样40个HXK4/64状态、同一线性模型和允许训练信息下，λ从1改为10后，
全局Spearman提高、MAE降低，但高值区分、固定池内高值前移及主G16收益仍不明确。
这次确实改变了复杂度和候选排序，因此不是“仅分数缩放、实际没有干预到排序”。
结果没有建立“正则化强度解释了上一轮ridge/XGB条件性收益”的证据，亦没有排除该解释。

原ridge前64池的40个状态中，14个池没有任何高值候选；原λ1另有8个状态虽有高值但G16零命中。
两类限制同时存在，前一类在固定池内无法仅靠重排解决。它不是整个候选库无高值，
也不识别为何上游预测把高值排出了前64，更不能作为稀疏性导致总体不确定性的因果贡献率。

## 比较与实际执行

[执行前便笺](../../experiments/M5_E3_RIDGE_STRENGTH.md)固定全部参数与解释边界。
仅用公开良性HXK4_HUMAN_Gersing_2022_activity，复用上一轮seed3000–3039的40个状态，
每状态原64允许标签、421输入、训练内标准化、自由截距、平方损失、固定贪心16。
目标mean MSE + λ||β||²，λ预列0.1、1、10；等价sum-loss惩罚α=64λ。
没有CV择优、追加档位、改变特征/标签/训练数量，或根据结果增加状态。

主分析固定原λ1预测的前64候选身份，分别用三个λ排序选16；两个主对比为0.1−1和10−1。
原XGB前64池、完整剩余池及10−0.1均为预列辅助。前64不增加揭示标签，成本均64+16=80。
主结果仍是top1%召回，分母86；下列命中差除以86即召回差。池依赖原参考方法，
结论条件于这个池，不能推广成任意池、完整模型流程或ridge相对XGB的总效应。

全部40个状态为配对统计单位，20000次bootstrap、PCG64 seed15001、99.375%描述性区间。
不挑有高值的状态；同一状态的三个λ与多个池不当成独立重复。未设应用δ，区间含零
不证明无效或等价，亦无全部历史分析的同时覆盖保证。新随机seed/独立测量均为0。

两个固定池的高值数量与候选身份在三个λ间逐状态相同。主池λ10平均命中略高，
但有命中的状态从18减至15；平均数量与“每个状态都更容易发现”不能混称。
完整剩余池40个状态全部有高值，λ0.1/1/10仍分别26/22/25个零命中。

本次把零命中定位到“前64内是否还有机会”这一可核验层面：H=0时池内排序上限为0；
H>0但零命中时尚有池内排序机会。min(H,16)是事后诊断上限，不是可部署oracle策略，
不进入选点。零命中分解不能解释原来两种方法差异的全部来源，不能判定训练信息不足、
模型泛化限制或测量噪声各占多少；只有每候选一个处理后标签，无法估计重复测量噪声。
