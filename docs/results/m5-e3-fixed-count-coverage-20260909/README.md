# M5/E3：固定训练数覆盖对照

2026-09-09，ITERATION / L1。60配对状态完成，运行与聚合核验通过；独立科学审核待完成。
对应[执行前便笺](../../experiments/M5_E3_FIXED_COUNT_COVERAGE.md)。

## 结论

平均可观测几何覆盖得到小幅改善，但没有建立固定G的高值发现增益；PABP/RF的near AUC
仍下降。结果削弱“这种平均组成空间覆盖改善足以解决问题”的解释，不能排除其他覆盖定义、
更大干预幅度或不同训练标签的作用，更不能证明局部排序是唯一原因。

“局部排序”需要拆开：near AUC比较真值top1%与接下来1%的候选，预测前端则是模型排名
前16名，两者不是同一集合。上一轮输入干预的PABP前16平均14.6–15.1个来自真值top2%
之外，因此near AUC下降不能直接解释全部选点错误。高值本来稀疏，多数选点非高值本身
也不证明异常或劣于随机。必须观察干预前后的配对变化，而非把“前端排序差”重述为根因。

## 对照与覆盖操纵

在原PABP、HSP82、HXK4三个良性任务中，固定421维表示、RF/XGB配置、每组32个训练
标签、G/E规则与16批量。仅将原随机32样本换为从既有64观测中无标签贪心选出的32样本。
选择最小化共同剩余池到最近训练点的平均平方距离，只用原420维组成频率，未用真值、
ESM分数或预测选样；该规则在所有结果前固定。两组都排除同64初始候选，成本均64+16=80。
这是已获取标签的训练子集诊断，不是只购买32个标签的采集效率实验。

| 任务 | 平均距离相对下降 | 十seed中改善数 | 平均保留原32训练点数量 |
|---|---:|---:|---:|
| PABP | 4.918% | 10/10 | 14.7 |
| HSP82 | 3.132% | 10/10 | 16.3 |
| HXK4 | 3.248% | 10/10 | 14.9 |

相对变化为两个seed均值之比，不是新显著性检验。三项平均距离差的99.375%描述区间均
低于零；干预幅度只有约3%–5%。90分位覆盖距离：PABP约下降5.55%，HSP82仅浮点精度
变化，HXK4约下降0.017%。尤其后两者不能被称为远端覆盖显著改善；接近零的数值区间端点
不作为实用变化证据。几何覆盖也不等同功能覆盖，换点同时改变标签组成，尚未分离其贡献。

## 固定G与排序结果

下表每项10个配对seed，区间为20,000次bootstrap的99.375%描述区间。top1%分母沿用
378/133/86，命中差除以对应分母即主recall差；不合并assay作总体区间，无应用delta。

| 任务/模型 | G命中：随机→覆盖 | Δ命中及区间 | Δnear AUC及区间 |
|---|---|---|---|
| PABP/RF | 0.8→0.8 | 0.0 [−1.6,1.2] | −0.01340 [−0.02388,−0.00009] |
| PABP/XGB | 0.4→0.4 | 0.0 [−0.7,0.8] | −0.00276 [−0.01721,0.01028] |
| HSP82/RF | 0.5→1.1 | +0.6 [−0.5,2.3] | +0.00224 [−0.02571,0.04025] |
| HSP82/XGB | 0.2→0.5 | +0.3 [−0.5,1.7] | −0.00891 [−0.04463,0.02505] |
| HXK4/RF | 0.3→0.9 | +0.6 [−0.6,1.8] | +0.01325 [−0.02767,0.04697] |
| HXK4/XGB | 0.0→0.7 | +0.7 [0.0,1.9] | +0.00799 [−0.04430,0.05867] |

六个主G区间都包含或触及零，不证明等价、普遍无效或真实效应恰为零。整体Spearman、
高值全局AUC差也均未严格排除零；不能把本轮统称为“预测明显改善但无收益”。PABP/RF
near下降的区间刚好低于零，属于多项开发诊断中的有限证据，不是独立因果确认。

一个辅助改善必须保留：HXK4/XGB前16中真值top2%以外的候选减少1.2个，区间[−2.7,−0.2]；
其中near候选增加0.5、高值增加0.7。主高值增益仍不能严格排除零，不能事后把top2%或
前端类别构成换成成功标准。其余E、best-found、首次高值排名、完整类别与训练标签组成
均在[结果](result.json.gz)及[验证汇总](verification.json)中，未选择性省略。

## 原因解释的边界

已固定训练样本数、模型/表示、候选池、初始最好值与成本，且覆盖操纵实际发生，因此
本轮不是简单重复32→64信息增加。但3%–5%的平均距离变化不能代表消除了训练覆盖不足。
当前仍没有证明“覆盖→局部排序→发现”的中介因果链；训练点标签组成、表示/训练目标、
可学信号与高值区噪声、稀疏命中的统计不精确仍可能共同作用。

更准确的当前判断是：预测改进没有稳定到达决定发现的排名前端，前端是重点排查位置。
仅以命中数或near AUC给这种现象命名不等于找到上游原因。本单元到固定矩阵结束即停止，
不追加seed、改距离或换训练数量直到出现阳性，也未新增独立任务确认。
