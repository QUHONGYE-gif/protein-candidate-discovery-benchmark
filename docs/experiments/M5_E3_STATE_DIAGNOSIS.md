# M5/E3：初始状态与收益波动诊断

2026-09-10，执行前便笺。ITERATION / L1，第3阶段；用户批准返回原因研究后继续。

原问题是固定策略下预测改善如何转化为发现收益，以及哪些因素影响这种关系。
整体机制完成需要受控干预及其收益响应；本单元只补齐状态与统计解释的诊断证据。
Scope verdict: ALIGNED / SIMPLIFY；purpose: DIRECT。
因果链：量化收益的状态分布、批次差与粗覆盖构成 → 判断哪些解释仍有支持 → 收窄下一原因干预。

## 本次问题和方法

1. 原收益是否集中于少数初始状态？所有任务同时报告每seed的新旧输入命中差、正/零/负数量、
   双臂零命中数量、最大正贡献占全部正贡献的比例，以及逐一去掉一个seed的均值范围。
   删除只作敏感性计算，原状态全部保留，不据此选择报告、排除异常值或调整方法。
2. 新旧批次的效应是否确有差别？直接报告“复测批次输入收益−原批次输入收益”及区间，
   并拆成新输入和旧输入各自的批次变化。批次不配对；32/64嵌套初始量始终共享seed抽样槽。
3. 初始是否已有top1%高值观测这一粗指标，能否在描述上解释批次差？仅由已发布的
   总高值数−剩余高值数恢复计数，按初始量分别报告0/至少1个的覆盖比例和组内收益。
   两批两组都实际存在时，将批次差对称分解为覆盖比例构成项与组内均值变化项。
   这是算术分解，不能作为因果贡献率；组小且条件信息有限，不作分组显著性或中介声明。
   全任务高值阈值来自既有评估器，不提供给模型或用来筛选训练样本。

固定范围：PABP/HSP82/HXK4，XGB，原10seed与复测20seed，初始32/64；共180保存状态。
主预算16不变，8/32/64完整作为辅助诊断，不因结果选截断。报告初始量分层及等权合并。
只读取三个身份绑定的既有紧凑结果：原输入干预、原前沿、复测full；不访问候选级数据。
报告同状态预测rho/AUC同时改善与收益正/零/负的联合计数，避免仅凭组均值解释传递。

区间继承99.375%描述性bootstrap、20,000次（PCG64种子12201、12202，分批独立）。
同seed的32/64先等权平均再重采样，assay分别估计；不把同名seed跨assay配对，不混合旧新
批次补强阳性。零包含不等于零效应；退化经验区间不代表总体不确定性为零。
同一数据、重复开发和看过批次结果后制定诊断，均不具独立确认含义。

## 有效性、预算与停止

运行前/中核对输入校验和、任务/模型/seed完整性、计数与分母、初始嵌套、原端点对应。
最小合成检查验证共享seed统计、独立批次差及覆盖分解恒等式；运行后独立算术实现复算。
Decision Guard：现有批准范围内、可逆的紧凑汇总计算，采用低成本压缩审查；没有规模放大。
备选是直接换模型或增加标签，但在当前问题尚未区分时暂缓。初始高值计数不是完整训练信息；
即使构成项很小，也不能排除标签变化、冗余、功能覆盖或表示不足。

预算：本地既有Python/NumPy环境；分析最多120秒、512MiB进程RSS、输出10MiB；
新拟合、新标签、新数据/依赖、服务器/COS/held-out/D访问及费用均为0。一个合成接通和一次full；
实现错误只允许一个有记录的修正attempt，不覆盖任何输入、成功结果或旧尝试。
输出源码/便笺/输入身份、逐状态汇总、上述区间/分解、命令和attempt、紧凑中文报告后停止。
解释分类可以是支持、削弱或不明确；不保证识别根因，不自动启动下一干预。
