# M5/E3：定向同位点支持增加，主发现收益仍不明确

2026-09-11，ITERATION/L1。第2阶段主体实验与第3阶段算术核验完成；
本有界单元完成不等于整体M5原因目标完成。

按“已有信息诊断→受控训练子集干预→响应解释”执行。在固定训练数下，定向配方确实
增加了原候选前端的同位点观测支持；ridge在固定池内的高值排名和有向前变化的辅助信号。
但两模型的主G16命中、高值AUC和near AUC改善仍不明确，尚未连成稳定发现收益的证据链。
这限制的是本次配方，不能排除训练信息不足，也未确认同位点支持是原收益的唯一原因。

## 设计与即时有效性

[执行前便笺](../../experiments/M5_E3_SITE_SUPPORT.md)固定了分析与边界。
公开良性HXK4_HUMAN_Gersing_2022_activity，8570个单点变体、464个位点；
沿用seed3000–3039共40个状态、每状态64条允许观测、421输入。
诊断阶段先锁定全部40个状态的训练子集，再评分；干预阶段先保存全部预测与选点，
worker退出后由原评估器评分。子集选择不接收标签或真值高值身份。

- random32：原64观测的标签盲hash顺序前32。
- support32：在同64条中选择32条，最大化原ridge预测前64的同位点支持，单个位点
  最多计2条；边际相同先未覆盖位点，再原hash顺序，零收益时按原hash补足。
- all64：原64条全部训练，逐值重建原XGB/ridge预测，作为辅助参考。

主比较分别在固定XGB、固定ridge内做support32−random32，主池为共同剩余8506候选，
排除全部64允许观测，贪心选16；top1%召回分母86，成本背景为64+16=80。
两主臂只用32条直接训练，但目标池来自原64标签模型，携带间接信息，不能称32标签
采集效率。固定原ridge前64内的重排和all64对比均为辅助，不替代完整池主结果。
38个状态子集不同，另外2个也按事前规则保留；全部40配对状态、不挑高值状态。

40状态估计同一已见assay内的算法状态变异，不是40个独立生物重复。20000次配对bootstrap、
PCG64 seed16001、99.375%描述性区间；未设应用δ、无全部历史比较的同时覆盖保证。
区间含零不等于证明零效应或等价。数据/允许观测/排除池/参考预测均按身份校验。

## 诊断与实际干预量

原64观测下，在40个状态合计3415条“高值候选×状态”记录中，452条有至少1条同位点
观测，只有18条有至少2条。原ridge前64内共有83条高值记录，其中55条有1条同位点观测、
没有任何一条有至少2条；原XGB前64内81条高值记录中28条有支持、1条有至少2条。
这些记录在状态间重复，只能描述现有信息结构；不能据此计算独立样本CI或判定信息充分。
大多数高值在前64之外也受64/8506的容量限制，单凭这个数量不能认定预测失败的原因。

| 定向前后的指标 | random32 | support32 | 差及99.375%区间 |
|---|---:|---:|---|
| 原ridge前64中至少1同位点观测 | 14.102% | 26.719% | +12.617个百分点 [8.477,17.520] |
| 前64中至少2同位点观测 | 0.039% | 0.469% | +0.430个百分点 [0.117,0.820] |
| 前64截断支持数合计 | 9.05 | 17.4 | +8.35 [5.625,11.525] |
| 整个剩余池有支持比例 | 6.438% | 6.436% | −0.0021个百分点 [−0.0639,0.0595] |
| 训练标签均值 | .67148 | .79207 | +.12059 [.08667,.15578] |
| 训练标签范围 | 3.17136 | 3.46675 | +.29538 [.08875,.53381] |

定向支持确实增加，但增加主要是“一条同位点观测”，不是充分的同位点功能对照。
训练标签标准差也增加+.07174 [.04131,.10466]。即使选择器没有直接读标签，选择的
样本身份、标签分布和输入分布仍会共同改变，因此不能将后面的变化只归因于同位点覆盖。
整个池的覆盖差不明确也不证明所有几何覆盖已等价。

## 主收益与中间环节

| support32−random32 | XGB | ridge |
|---|---|---|
| 主G16平均命中，前→后 | .300→.525 | .825→1.175 |
| 主命中差及99.375%区间 | +.225 [−.100,.600] | +.350 [−.100,.975] |
| 完整池top1% AUC差 | +.00665 [−.00577,.02004] | +.01651 [−.00350,.04003] |
| near AUC差 | +.00106 [−.01275,.01514] | +.00426 [−.01316,.02297] |
| 预测前64高值数差（辅助） | +.250 [−.300,.925] | +.550 [−.375,1.950] |
| 固定原ridge池G16命中差（辅助） | +.100 [−.100,.325] | +.350 [−.100,.975] |
| 固定池高值排名和差（辅助，负为前移） | −2.775 [−9.963,3.800] | −23.450 [−55.138,−2.312] |

主召回差分别是+.2616个百分点 [−.1163,.6977]、+.4070个百分点 [−.1163,1.1337]。
总体Spearman变化仍不明确；两模型MAE分别恶化+.02051 [.00245,.04198]、
+.02446 [.01320,.03670]。因此这轮不能叫“整体预测更准确并带来发现收益”。

ridge固定池中，高值排名和均值从65.125降到41.675。它是每状态池内所有高值名次的和，
不等于每个高值都向前；高值更多的状态对排名和影响更大。高值池和数量逐状态固定，
无高值状态排名和为0、不删去；该池仍14/40状态无高值。这个辅助量与命中共享排序和真值，
不能当作独立中介证据。固定池AUC只26/40可定义，未按可定义子集计算总体CI。
模型内三个前64的并集AUC分别31/40与34/40可定义，也未填零或做完整案例CI。

两个主命中差的直接模型交互为+.125 [−.525,.850]，不能声称ridge响应明确强于XGB。
all64辅助对比也未建立主命中收益；所有端点和正负结果见[全部端点](all-endpoints.md)。

## 稀疏命中与状态差异

| 模型 | 收益正/零/负状态 | random32零命中 | support32零命中 | 两臂均零 | 任删1状态的差均值范围 |
|---|---:|---:|---:|---:|---|
| XGB | 8/28/4 | 32 | 28 | 25 | [.17949,.25641] |
| ridge | 11/25/4 | 26 | 22 | 18 | [.20513,.41026] |

两臂至少一命中的状态各增加4个，但仍存在大量零命中。任删一个状态均值为正不等于
主区间排除零，更不能把“噪声/样本量”作为已经识别的原因。仅有每候选一个处理后标签，
本设计没有独立重复测量，无法估计测量噪声贡献。
