# M5/E3：固定数据的排序目标对照

2026-09-09，ITERATION / L1。60个配对状态完成；运行与聚合复核通过，独立科学审核待完成。
对应[执行前便笺](../../experiments/M5_E3_RANKING_OBJECTIVE.md)。

## 结论

单一成对排序目标没有建立固定G的发现增益，也没有稳定改善高值区区分。原回归模型在
允许训练样本上的整体排序已经接近完美；换目标后仍如此。结果削弱“只要改成这个排序
训练目标就能修复前端”的解释，没有证明排序不重要或发现收益普遍为零。

当前定位更接近高值区的样本外区分问题，但这仍不是唯一上游原因：高值训练例稀少、
表示信息、噪声及模型泛化可能并存。本轮没有分离它们，也不能从训练/池内表现差直接
确认过拟合。此前的near AUC下降不是所有任务的共同机制，本轮也没有统一方向。

## 对照

三项既有良性C，XGBoost原树参数、421维输入、原32/64训练样本和十seed固定。两臂
共享样本ID、标签、输入、候选池、初始最好值和80标签成本；仅切换平方误差与固定成对
排序目标（mean配对、每样本4对、两项归一化开启）。排序标签是允许观测的升序稠密秩，
保留相等关系。目标专有配对/归一化属于本次实现，不能声称理论损失尺度已被完全隔离。

原回归点预测在每个状态都重新拟合并与原保存预测逐值相同，随后对照排序点预测。G均
按分数取前16。没有新的bootstrap、E或M比较；排序分数没有标签量纲，不比较MAE，也不
复用原mean+sigma语义。RF、GFP、A/B、D及新数据未扩入本单元。

## 主要结果

每格10个配对seed，20,000次bootstrap，99.375%描述区间；32/64分别报告，不作为20个
独立重复；不合并assay建立总体CI，无应用delta。top1%分母沿用378/133/86。

| 任务/训练数 | G平均命中：回归→排序 | Δ命中及区间 | Δ池内Spearman及区间 |
|---|---|---|---|
| PABP/32 | 0.4→0.2 | −0.2 [−0.6,0.0] | +0.0620 [0.0160,0.1067] |
| PABP/64 | 0.7→0.8 | +0.1 [−1.3,1.2] | +0.0301 [−0.0025,0.0678] |
| HSP82/32 | 0.2→0.2 | 0.0 [−0.5,0.5] | +0.0127 [−0.0144,0.0406] |
| HSP82/64 | 1.7→0.1 | −1.6 [−5.6,0.2] | −0.0222 [−0.0417,−0.0038] |
| HXK4/32 | 0.0→0.3 | +0.3 [0.0,0.7] | +0.0287 [0.0030,0.0534] |
| HXK4/64 | 0.3→0.1 | −0.2 [−0.6,0.0] | +0.0022 [−0.0208,0.0254] |

六个主命中区间均包含或触及零，不是等价证明。PABP/32、HXK4/32整体排序改善，HSP82/64
下降；其余不明确。六格全局高值AUC及near AUC变化区间均含零。预算32/64的辅助命中
变化也未严格排除零；全部best-found、首个/中位高值排名及类别构成保留在结果中。
HXK4/32 best-found点改善、HSP82/64与HXK4/64点下降，其区间亦含或触及零，不挑选性省略。

两种方法前16平均仅重合0.8个（60状态的描述均值），选点行为确实改变；不同选点不等于
更好的选点。原回归训练内Spearman各格均值0.99967–0.99989，排序目标0.99558–0.99879，
小幅下降但都很高。本轮不是“训练内排序提高了但无法泛化”；训练整体拟合原本已很强，
不能据此推断高值边界已经从稀少训练标签中学会。

共同前端由两臂预测前64的并集构成，先于真值评分保存。五格仅6–9/10状态定义了高值

[−0.3529,0.2369]，不明确。共同前端属于由模型定义的条件集合，不是新的独立验证集；
高值稀疏会使它缺高值，本身不证明异常或劣于随机。

表最后一列是看到本轮结果后，对[既有训练信息汇总](../m5-e3-training-information-20260909/result.json.gz)
的描述性复算，来源为XGB每seed的`initial_coverage`，不是新实验或前瞻检验。没有另读
候选级真值或按高值挑选训练点。它说明当前初始观测经常没有直接高值例，不能证明该
稀疏性造成弱发现，也不能据此改用oracle选样。数量32→64与覆盖干预已有结果，尚未
分离高值样本不足、功能表示与噪声；需要更有区分力的上游证据。
