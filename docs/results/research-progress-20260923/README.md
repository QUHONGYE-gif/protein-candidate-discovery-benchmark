## 当前结论

- 新增分组、整体偏差及上尾组件没有建立稳定的增量主发现效果。
- 两个 ESM 来源在严格 Top1% 下未获得所测静态组合收益；较宽目标下有 BLAT 和部分低价 GFP 的条件性正向，必须保留，不能称所有组合均无用。
- ACS 小分子多保真方法重建没有取得跨两任务稳定收益；NR1A2 后续表明局部正差对拟合设置敏感。不是原图精确复现，也不否定原论文。
- GB1 原表的计数字段已找到；原表536,962个单/双突变键与当前 ProteinGym 来源一一对应，既有三个开发池768个身份均匹配。仅身份接通，不是信号有效。
- [四缺口审计](GB1_AUDIT.md)判定：映射已接通；购买前可见性有条件、原实验没有分阶段返回证据；真实成本未知；计数识别 ESM 漏筛的增量价值未证实。#113 仍不是可执行方法，#114/#115 不启动。
