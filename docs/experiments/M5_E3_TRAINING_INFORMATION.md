# M5/E3：共同候选池上的训练信息对照

2026-09-09，执行前便笺，ITERATION / L1。承接用户批准的第二步原因分析。
Scope：ALIGNED / DIRECT。改变模型可学习的既有观测数量→测量预测前沿及固定策略收益
响应→检验训练信息是否限制预测改进的转化。执行顺序在GFP完整对照完成后。

## 最小干预与可排除的混淆

仅复用三项良性C（PABP、HSP82、HXK4）的已保存预测，不新增拟合或标签访问范围。
每assay/model/seed将原32与64嵌套观测状态配对，两种表示分别保持固定：420维，以及
420维加固定ESM1v。模型配置、G/E方法与16批量不变，共3×2×10=60个配对块。
四臂是两种表示×32/64训练观测；全部四臂在同一候选集合上选点和评估。

共同剩余池排除原64个初始候选。将32观测模型的保存预测限制到此池，64观测模型预测
原样使用。两者均以相同64个已获取标签和再选16个标签为成本背景，即80个标签。
32臂只允许模型学习前32个标签，另外32个标签的获取成本仍计入，已发现收益也同样计入。
这是一项信息删减诊断：在已经取得64个标签的背景下，利用后32个标签是否有帮助。
它不是“花48个标签与花80个标签”的预算平价比较，也不是经济最优策略或多轮学习曲线。

这能控制候选移出池、初始最好值、已获取标签成本和批量差异；不直接隔离空间覆盖与
样本数量，也不声称额外标签有独立普遍价值。更多标签的内容与覆盖共同变化，须根据实际
预测响应判断干预是否生效。初始高值覆盖仅作评估器事后描述，不用来挑选seed或分组。

## 指标与核验

主比较：固定每种表示后，64−32的共同剩余池Spearman与固定G的top1%命中/recall。
同时报告MAE、高值全局/近邻AUC（近邻仍为top2%内非top1%）、固定E收益和best-found。
补充两种表示的训练信息效应差，检查公开先验的响应是否随训练信息改变；保留全部单元。
同assay/model按10个seed配对bootstrap20,000次，99.375%描述区间；不再将32/64计作
20个重复。无应用delta、无总体跨assay CI，不按显著性挑选处理、seed或延长实验。

预测及选择身份绑定已完成的E3输入结果和前沿结果。worker仅读保存预测和候选ID，
先保存共同池、四臂排序和G/E选点后退出；评估器再打开既有真值评分。禁止新fit入口。
初始32必须严格包含于64，四臂候选和指标分母相同；64臂G/E与原结果精确相等。
样本/标签、输入哈希与membership核验沿用已批准缓存；进程数据流隔离不等于OS隔离。

检查近邻排序与top16是否仍脱节；若预测本身不改善，不能据此判定训练信息不重要。
