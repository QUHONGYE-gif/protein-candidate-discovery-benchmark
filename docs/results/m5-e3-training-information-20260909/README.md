# M5/E3：共同候选池训练信息对照

2026-09-09。ITERATION / L1，60配对seed块、480确定性分支完成；独立科学审核待完成。
对应[执行前便笺](../../experiments/M5_E3_TRAINING_INFORMATION.md)。

## 这轮检验了什么

仅复用前三项良性C的保存预测，在两种固定表示中分别比较32与64训练观测，模型/策略不变。
四臂统一排除原64个初始候选，并共享相同初始最好值和已发现收益；每组均按64已获取标签
加16选点、共80标签计费。32臂有32个已付费标签不用于模型学习。
这是既有标签的信息删减诊断，控制了候选移出池、初始基线及计费差异；不是新测量实验，
也不是证明多买32个标签划算。样本数量与所含覆盖共同变化，未单独操纵覆盖。

## 主要结果

所有12个assay/model/表示单元的全池Spearman及高值AUC点估计都随32→64增加；
其中6个Spearman差、5个AUC差的描述区间严格高于零。训练信息确实能改变预测，
但没有一个固定G的主命中差区间严格排除零。部分区间端点为零，包括一个观察差全零的
退化区间；这不构成实用等价、总体无效或排除未见seed收益的证明。

下表列加入公开先验的表示，原表示与全部辅助指标均在[验证汇总](verification.json)中。

| 任务/模型 | ΔSpearman（64−32）及99.375%区间 | ΔG高值命中及同覆盖区间 |
|---|---|---|
| PABP / RF | +0.0342 [0.0082,0.0733] | −0.2 [−1.2,0.6] |
| PABP / XGB | +0.0567 [0.0103,0.1027] | +0.3 [−0.6,1.3] |
| HSP82 / RF | +0.0303 [−0.0127,0.0643] | +0.8 [−0.1,1.8] |
| HSP82 / XGB | +0.0306 [−0.0042,0.0706] | +1.5 [−0.4,5.6] |
| HXK4 / RF | +0.0096 [−0.0163,0.0473] | +1.1 [−0.6,4.0] |
| HXK4 / XGB | +0.0195 [−0.0126,0.0515] | +0.3 [0.0,0.7] |

PABP/RF公开先验臂更具体：整体Spearman增加0.0342，高值全局AUC增加0.0195
[0.0044,0.0431]，但高值对近邻负例AUC下降0.0090 [−0.0199,−0.0004]。
因此，在本次相同候选池与成本背景下，更多训练信息仍可能改善全局排序而损害近邻区分；
此前PABP出现的断点并未仅靠多利用32个标签消失。不能据此排除更大训练量的收益，
也不能将该现象推为所有任务的共同根因。

辅助E结果出现一个不能省略的差异：HXK4/XGB的训练信息效应在加入先验后相对原表示
减少0.6个命中，交互描述区间[−1.2,−0.1]。这支持该开发对照中E响应并非简单相加，
但不是主G结论，也没有把均值与sigma贡献拆开；多项探索诊断不能当作独立确认。
完整单元包括零、负与不明确结果，未按它们选择模型、seed或追加运行。

## 解释推进到哪里

- 本轮配对已消除四臂候选池、初始最好值、已获取成本和批量不一致的机械混淆；
  预测/发现差异不能在本轮再直接归咎于这些口径差异。
- 训练信号能改善全局预测，故并非所有单元都处于“增加信息完全学不到”的状态。
  但改善不保证到达高值近邻及top16；PABP给出了该断点在另一种信息变化下仍存在的证据。
- 命中稀疏与区间宽度仍限制收益判断；样本量/覆盖/表示相互作用、具体排序失效的上游机制
  及独立任务确认尚未解决。这不是唯一原因的最终识别，也不是“只需增加数据”的证明。
