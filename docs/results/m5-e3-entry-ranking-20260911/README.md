# M5/E3：前端与排序交叉尚未定位主收益原因

2026-09-11，ITERATION/L1。保存预测的主体分析和独立算术核验完成；整体M5原因目标仍开放。

本轮将上轮各训练臂的前64池与排序交叉，四个主对照的对称池替换、池内排序分量均未明确。
因此不能把主收益不明确归为其中一个环节，也没有确认两者互相抵消。固定参考池的XGB
辅助改善未在其自身前64池中建立明确响应，但池间收益变化差也未明确，不能据此确认池依赖。
零命中确实同时包含“池内没有高值”和“池内有高值但未选中”；这是决策层位置，不是上游原因。

对于旧臂A和新臂B，YAB表示在A的前64池中按B的冻结预测排序选16，另有YAA、YBA、YBB。
自组合逐值重建原前16；任何交叉选择都在评分前确定。总差D=YBB−YAA；
对称池分量P=((YBA−YAA)+(YBB−YAB))/2，排序分量R=((YAB−YAA)+(YBB−YBA))/2。
D=P+R逐状态精确成立。两条顺序路径、交互和P−R直接区间都报告；这是条件性计算分解，
不能独立识别训练信息、表示或噪声，也不能把同一排序/真值导出的量当作独立中介证据。

## 固定参考池与完整池的差距

令F为原ridge64参考池，J=完整池G16命中−F内G16命中，则D=ΔF+ΔJ。
这个恒等式描述净变化，不能仅据J辨认哪些具体高值被池外候选挤掉。

| 主比较/模型 | 固定参考池变化ΔF | 完整池变化D | 差距变化ΔJ |
|---|---|---|---|
| A/XGB | −.200 [−.525,.025] | +.100 [−.075,.300] | +.300 [.025,.625] |
| A/ridge | −.075 [−.250,0] | −.100 [−.325,.075] | −.025 [−.150,.075] |
| B/XGB | +.175 [.025,.400] | −.050 [−.400,.225] | −.225 [−.600,.075] |
| B/ridge | −.025 [−.225,.125] | −.075 [−.375,.125] | −.050 [−.250,.150] |

B/XGB的旧辅助固定池改善被精确重建，但ΔJ仍含零，不能确认该改善被池外竞争抵消。
其完整池前16中F外数量13.075→13.775，差+.700[−.050,1.625]也不明确。
A/XGB的ΔJ区间为正，表示该指定对照的完整池变化比固定参考池变化更正；两边各自收益
仍不明确，不能当作主发现收益或一般池依赖机制。固定池指标不应代替完整池主指标。

## 零命中来自两处，仍不等于根因识别

前64高值数H64、主命中H16，理想容量C=min(H64,16)、未实现容量L=C−H16；
ΔH16=ΔC−ΔL。全部已见H64≤16，所以本次C=H64。C只是理想重排上限，不是模型可获得
的信息、可实现策略或已识别的可修复错误；L不解释为何排序没有实现该上限。

每行三类状态合计40；不能用两行边际数量变化推断是同几个状态发生了转移。
B/XGB匹配后28个零命中状态中，13个池无高值、15个有高值但没选中；ridge为12+12。
只改善池内排序无法解决当前池无高值的状态；只让高值进入池也不保证选进前16。
但当前干预没有识别两类问题的相对因果贡献，更不能归因只是样本量、测量噪声或训练不足。
