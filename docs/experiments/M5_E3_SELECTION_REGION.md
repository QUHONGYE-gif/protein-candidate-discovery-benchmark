# M5/E3：预测改善位置与最终选择区间的直接比较

## 问题、对照与范围

原问题：固定G16后，预测改善是否到达实际竞争选择名额的区域？
可观察完成条件：同状态、同一组真实高值下的两个负例区域改善量及直接差、
实际高值排名迁移和主命中变化得到报告；旧/复测批次分开检验重复性。
Scope ALIGNED/DIRECT：固定预测定义区域→评估配对区分改善的区域差→检验改善位置错位。
不重做模型训练，不用恒等分解声称训练信息或表示根因已被识别。

仅PABP/HSP82/HXK4原固定420→421输入干预保存预测：
原10seed×32/64×RF/XGB×3任务=120状态；已完成复测的20seed×32/64×XGB×3任务=120状态。
两批分别报告，不合并为独立确认；RF没有对应新批，不能声称RF已复现。
GFP既有干预未建立预测改善，保持其已知例外，不列入这条已改善干预的定位单元。
不新增assay、状态、标签、模型、依赖、D优化、held-out或COS；原成功结果只读。
主预算16、全任务top1%定义及分母、原样本/标签方向/配对关系不变。

## 预先确定的区域和指标

对每一配对状态，由纯预测worker锁定旧/新全部候选排序（分数降序、candidate ID打破平局）：
U=旧前16与新前16的并集。它仅用已保存的预测，不看真值。
worker退出后，原评估边界内部用既有top1%身份，把负例分为
H=U内的非高值候选，O=U外的非高值候选。
两组使用同一组剩余池真实高值作为正例；不是把模型前16当作真实高值邻域。

对旧/新分别计算AUC_H、AUC_O及AUC_all。AUC解释为高值比分组负例预测分数更大的比例，
相同分数计0.5。两组按负例数加权必须精确还原全池AUC。
主定位量：D=(AUC_O,new−AUC_O,old)−(AUC_H,new−AUC_H,old)。
直接在配对状态上计算D及区间，不比较两格是否各自显著。
两个AUC按配对数归一化，避免仅因O候选多就称其改善更大。
同时报告各区域候选数、原/新水平，明确这是按两模型输出定义的条件性难负例集合，
不是与模型无关的生物分区或随机处理，区域差不能独立证明上游因果。

固定敏感性：分别以旧前16、新前16为参考，重算区域差；全部报告，不择优。
不新增其他K、阈值、分层或调参。未定义AUC保持null，报告支持数；若任一状态未定义，
不删除该状态对剩余子集算主区间。

位置验证：对所有真实高值，报告排名上升/下降/不变的数量，
其中上升但旧/新均未进前16的数量、进入/退出/保留前16的数量，以及首个/中位排名。
进入减退出必须等于主命中变化。归一化以剩余高值数为分母。
上升者中仍在外部的比例只是描述，不能忽略原本在外部的高值基数或据此计算因果解释率。
原/新G16命中及全池AUC必须重建已有结果，未建立增益不能写成零效应。

## 统计与停止

每assay、模型和批次分别报告；同seed的32/64先等权平均，再对seed槽做20,000次配对bootstrap。
PCG64固定seed19001，继承99.375%描述性百分位区间；同时保留32/64分层。
六个XGB assay×批次主定位量预先指定，原RF为补充；不同assay不混合统计。
强度判断：同一assay的XGB旧/复测批次均有全池预测改善且主D区间严格大于零，
则支持该指定区域定义下“改善更偏向最终竞争区域之外”的可重复开发期现象；
没有同时达到时分别报告支持/相反/不明确。所有任务均报告。
参考区域敏感性改变方向时说明依赖定义，不能由主定义单独升格为稳健一般结论。
不要求AUC_H或命中效应等于零；区间包含零不证明等价。现有数据均已见，不称独立确认，
没有全部历史探索的族错误率保证。此处较强指直接配对和批次重复，非生物因果确认。

固定矩阵一次完成后停止，不根据结果扩seed/K/任务/模型或尝试新区域直到阳性。
若区间仍不明确，报告剩余可识别性问题；不把第一项自动标为原因已排除或整体机制完成。

## 实施与有效性

复用原服务器、身份绑定缓存和Python环境，单worker/单数值线程。
预测worker仅接收候选ID、缓存定位和必要SHA/状态身份，不接收历史评分行、完整真值或高值身份。
每批全部排序与区域锁定、worker退出后，既有评估器在其边界内部读取原top1%身份计算聚合；
无reveal、无标签回流、无原始分数/高值身份回传。该计算属于原评估器内的新聚合诊断，
不声称本单元与只调用evaluate_batch的上一交叉单元有相同内部访问路径。
进程/数据流隔离，不宣称同账号操作系统强隔离。各assay评估器销毁后才处理下一assay worker。

先合成检查排序/AUC ties/缺失/配对分解，再跑9状态smoke（原两模型及复测XGB各任务1状态），
重建旧端点通过后一次full240状态。结果侧独立核验不导入执行脚本，使用紧凑计数重算关系及区间。
源码、便笺、输入、预测、选择、实际argv及attempt时间同步保存，所有输出新建。

总计算上限15分钟，RSS1.5GiB，新增磁盘256MiB，紧凑回传10MiB，无新增付费资源。
smoke上限120秒，full600秒；最多一次非科学配置变更的实现修正或瞬时重试，失败保留新attempt。
身份、标签、配对或边界错误立即停止；额外数据/资源范围另行明确。
