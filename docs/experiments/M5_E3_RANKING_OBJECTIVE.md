# M5/E3：固定数据的排序目标干预

2026-09-09，执行前便笺。用户批准继续检验排序训练目标。ITERATION / L1；
Scope ALIGNED / DIRECT：改变训练目标 → 核验前端区分及固定G响应 → 区分预测改善
为何未传递。成功条件是形成可解释的配对效应与限制，不要求收益阳性。

只使用既有三项良性C（PABP、HSP82、HXK4）、原421维表示、XGBoost 3.2.0及原
32/64初始训练样本、十seed。RF无同类原生目标切换，本单元不替换算法；GFP、A/B、D、
外部确认和新数据均不在本单元内。两臂排除同64初始候选，按64已获取标签+16选点计80。
各训练数量内样本ID、标签、特征、模型树参数、初始最好值和策略完全相同。

对照原`reg:squarederror`与唯一固定`rank:pairwise`；后者用`mean`配对、每样本4对、
两项lambda归一化开启、unbiased关闭，其他树参数保留。排序标签只是允许观测的稠密
升序整数秩，保留相等关系，不用真值分位阈值；没有距离、目标、参数或标签阈值搜索。
这是目标实现干预（包含配对/归一化和目标专有默认值），不声称仅改变理论损失尺度。
选择依据是[官方小样本排序说明](https://xgboost.readthedocs.io/en/release_3.2.0/tutorials/learning_to_rank.html)
及[参数说明](https://xgboost.readthedocs.io/en/release_3.2.0/parameter.html)。

每状态重拟合原回归点预测并与已保存预测精确核对，再拟合排序点预测。G仍按分数降序
选16、ID破平局；原G使用点预测，不需要新bootstrap。排序分数不具标签量纲，因此不
比较其MAE、不复用均值+sigma的E语义、不据此宣称UQ改善。未新增M或探索策略比较。

主终点：top1%命中/recall与best-found。诊断：全局Spearman、高值AUC、near/far AUC、
首个/中位高值排名、前16类别、预列top32/64命中、训练内Spearman。额外冻结共同前端：
两臂各自预测前64的并集，先于评分保存，在同一集合计算高值AUC。该集合由预测定义，
只是条件诊断，不是独立验证；无正/负样本则记未定义，不填0、不删状态凑显著。
训练内排序改善但池内未改善只支持拟合/泛化断点，不能区分表示信息不足、噪声和过拟合。
前端改善而主16无明确收益保留预算与精度解释；目标干预未改善前端不能证明排序不重要。

3 assay × 2训练量 × 10seed =60状态；各数量每任务10配对seed，20,000次bootstrap、
99.375%描述区间，不将32/64当独立重复、不合并任务作总体CI、无应用delta。
条件指标只有10对均定义才计算区间，否则报告定义数及全部逐seed汇总。
稀疏命中、反复开发、多指标与已有任务选择限制保留；不据含零宣称无效或等价。

先6状态接通，再固定60状态（full120个点拟合）。只按运行有效性决定继续，不看收益
调参。累计40分钟、1.5GiB RSS、1GiB新增输出、5MiB紧凑回传、最多一次机械修复；
原服务器/身份/依赖，零新测量、费用、COS、held-out或受限任务。原成功数据只读。
worker仅收到固定允许观测及特征，预测、排序、共同前端先保存，worker退出后评分；
不声明OS级拒绝访问。身份/标签/比较错误或资源超限立即停止。所有尝试同步留存。

方法决策采用既有低成本范围：固定单一排序实现能直接检验目标因素；替代路线是采新标签
或更换表示，均引入新混淆/范围，暂不做。负结果不能排除其他排序损失或更大训练量。
