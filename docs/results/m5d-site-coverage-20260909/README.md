# M5D 第四阶段：OOF 位点覆盖分层结果

**结论：inconclusive / revise。** 已在唯一权威服务器 `129.28.97.247` 完成固定分析，属于 ITERATION 开发证据，独立审核 PENDING。

本轮复用 F2＋XGBoost 的 180 状态、720 折、8,640 条 OOF 预测，零新拟合、零 COS 写入。每折仅依据训练候选位点生成覆盖掩码，随后评价已揭示初始观测；不改变原正式结果、模型、特征、beta 或指标契约。

## 关键发现及优化含义

- `3BT1_A_U` 全池 235 个候选对应 235 个不同位点，均为单例；全部 960 条 OOF 记录位点未见，0/20 状态满足同状态两层各至少 4 条的条件。对池中任意留出候选，其他候选都无法提供同位点训练观测；增加种子或在同池重抽样不能解决。
- `1A22_A_B` 有 83/93 个候选至少含一个全池单例位点；928/960 条 OOF 记录含未见位点，仅 2/20 状态有共同支持，低于事前固定的 10 状态门槛。两个弱复合物的主问题无法由这批组内对照回答。
- 其余 7 个合格复合物中 6 个的未见位点 MAE 更高，预测秩相关差均为负；`1DAN_HL_TU` 的 MAE 差反向。仅在有支持的 2 个组等权汇总，MAE 差为 +0.3651 kcal/mol、状态比值均值为 1.3422。该条件子集不能替代两个弱组或全队列结论。
- 仅单突变敏感性分析只剩 `1AO7_ABC_DE`、`1DAN_HL_TU` 合格（同属一组）：MAE 差分别 +0.0026、−0.5854。样本与可比较组发生变化，因此敏感性汇总反向不能解释为消除了突变数混杂。sigma–误差相关差也没有统一方向。

**下一步建议（尚未执行）：** 将问题修订为“跨位点共享表征能否改善未见位点的均值排序”，只设计一个固定模型/采集规则的共享表征对照，保留 F2 基线及既定开发评估，不继续加密 beta 或 seed 搜索。上一轮 F3 局部窗口已测试，不能将其简单重跑作为新验证；新表征需先明确可用公开输入、身份与资源，再实施。当前结果说明覆盖可获得性的结构限制，尚不能证明误差的因果来源，也未证明任何替代方法有效。
