## 将稀疏变化和正负状态差异分开

D为每seed的命中增量；q为非零比例，a为非零组均值，p为其中正方向比例。
固定分解Var(D)=Vzero+Vdirection+Vmagnitude：

- Vzero=q(1−q)a²，零变化与非零变化组的均值差。
- Vdirection=q p(1−p)(正组均值−负组均值)²，非零状态正负组的均值差。
- Vmagnitude为同方向内的幅度方差，按各组比例加权。

全部为经验总体方差（ddof0），单位命中数平方；均值方差估计对应各项除以(n−1)。
分组由结果定义，贡献不是可实施干预或原因解释率；近零净均值会使Vzero变小。
