# M5/E3：改善位置的直接比较未确认“区间外改善更多”

执行2026-09-11，整理2026-09-12。ITERATION/L1，第1–3阶段完成，进入第4阶段整理。
对应[执行前便笺](../../experiments/M5_E3_SELECTION_REGION.md)及

## 结果与解释

**本轮没有达到预定的“改善更偏向最终竞争区域之外”的可重复支持标准。**
原六个assay/model单元及复测三个XGB单元的主区域改善差D，99.375%描述区间均包含零。
因此不能把第一项确认为主要原因，也不能据此排除位置错位或宣称两区域改善相同。

同时得到一项需要修正旧解释的结果：三项XGB复测中，
对曾进入新旧前16的非高值竞争者，高值区分AUC也明确改善。
“预测只在外部改善，前端竞争者的区分完全未改善”不符合本轮这一指标下的结果。
这里的区分是全部剩余高值与这些竞争者的成对比较，不等于最终前16内部排序或命中已改善。

主命中改善仍不明确。排名上升的高值候选中，约98.7%–99.8%在新旧两臂都未进入前16；
但原本约98.8%–99.8%的高值就处于两臂前16之外。这个比例有很大的基数影响，
不能仅凭“多数改善仍在外部”认定原因或计算因果解释率。
本单元有界分析到此停止，没有改区域定义、K、seed或模型去追求原假设成立。

## 实际比较

复用三项良性任务的原固定输入干预保存预测：原120状态（RF/XGB、32/64、10seed），
复测120状态（XGB、32/64、20seed）。零新拟合、标签、状态或assay；旧/复测分别报告。
G16与全任务top1%定义不变，分母PABP378、HSP82 133、HXK4 86。
GFP既有输入未建立预测改善的例外继续保留；不冒称本轮覆盖联合A/B/C/D或独立外部验证。

纯预测worker锁定U=旧前16∪新前16，并保存完整排序。
全部三个assay的worker退出后，执行脚本的评分阶段按既有高值身份分出：
H=U内非高值竞争者，O=U外非高值候选。两组都与同一组剩余高值比较。
U平均约25.9–30.05个候选，负例约24.35–29.30个；不是固定32个，也不按真值定义U。
H和O的AUC按各自候选对数归一化，按负例数量加权精确还原全池AUC。

D=ΔAUC_O−ΔAUC_H，直接对配对D计算区间，不比较两格的显著/不显著。
H由两模型输出选择，通常包含特别难区分的负例；它不是随机负例样本，
其AUC低于0.5不能解释为模型劣于随机。该区域比较是条件性诊断，不是随机区域干预。

## 定义敏感性与实际选择

固定敏感性采用旧前16或新前16作为参考，再重算D。三个复测XGB单元如下：

| assay | 旧前16参考D | 新前16参考D |
|---|---|---|
| PABP | −.1496 [−.2428,−.0655] | +.1675 [+.1148,+.2285] |
| HSP82 | −.0945 [−.1437,−.0496] | +.0809 [+.0549,+.1104] |
| HXK4 | −.0167 [−.0549,+.0194] | +.0672 [+.0406,+.0931] |

点估计方向随参考集合改变；原批也有同类方向变化，全部保留在完整表。
不能只选新模型的前16作为参考，便宣称“其他区域改善更多”是稳健机制。
这些是由模型输出决定的不同条件集合，不能归因某个独立生物区域或构造新的部署规则。

实际高值进入/退出前16的每状态均值（复测XGB）：
PABP .375/.400，HSP82 .175/.100，HXK4 .250/.225。
两者之差精确等于主命中差，说明存在实际进入和退出；
不是所有高值都没进入，也不是预测改善后选择完全没变。
净差仍不明确，这个恒等关系不能证明抵消是上游因果机制。

## 第一项现在能得到的结论

在本轮预定区域指标下，第一项的“区间外改善更多”尚无明确、可重复支持；
“对前端竞争者完全没改善”的更强说法则受到直接结果限制。
能够保留的是：平均区分与最终16个选择仍不能互相替代，前端参考定义影响描述方式。
训练信息、表示/学习限制、状态不精确仍未被排除，整体M5机制未完成。
继续第一项若需更强的因果说明，应针对实际选择边界提出独立可区分的对照，
不能只重复中位排名或换区域直到得到期望方向；本单元不自动扩量或转入第二项。
