# M5/E3：排序前端与均值／不确定性拆分结果

2026-09-09。阶段1接通、阶段2主体分析、阶段3解释完成；本目录为阶段4仓库整理。
证据为 ITERATION / L1；当前结果待独立科学审核，不代表联合M5完成。

## 得到了什么解释

**预测改善与发现改善之间的断点已更具体，但尚未找到唯一原因。**

- 三项任务的整体高值AUC及高值候选的中位排名改善，不能再用“预测根本没改善”解释本次干预。
- PABP的高值对近邻负例AUC反而下降：整体改善主要来自与其他负例的大量比较。HSP82的近邻
  AUC则改善，说明“不能区分高值附近候选”不是跨任务统一解释。
- 所有主批量16的命中差区间仍包含零。整体/中位排序前移不等于极少量候选进入最前端。
  PABP/XGB在预先列出的32、64截断处有正向描述性区间，提示预算边界有作用；不得据此
  把主批量改为32/64、声称多轮收益，或把该单元推广到其他任务。
- XGB四分支的条件均值效应、条件sigma效应、交互及总效应，在主高值命中指标上的区间均包含零。
  因此仍不能将变化明确归因于均值或不确定性，更不能据点估计选出新的“最佳组合”。

这里定位的是指标、排序位置与预算之间的断点，尚未解释导致该排序形态的表征、覆盖或噪声原因。
候选进入/退出及分类计数是诊断，不是上游因果机制。

## 实际过程与比较口径

[执行前便笺](../../experiments/M5_E3_FRONTIER_DECOMPOSITION.md)在本轮结果读取前保存。
仅复用[上一轮输入干预](../m5-e3-input-intervention-20260909/README.md)保存的旧/新预测，
三项良性C任务、两个模型、原32/64初始量及十个seed，共120个原状态；零新拟合、零新增观测。

1. 单独spawn worker仅接收候选ID和旧/新预测，校验同一剩余池与原选择，先落盘均值排序
   及混合分支。每个assay的worker退出后，评估器才读取既有隐藏真值评分。
2. 主高值定义保持top1%。近邻负例为原top2%中不属于top1%的候选，其余为far负例。
   “近邻”指真值分数范围，不是模型的当前选点边界；全部分组只存在于评估器。
   两类AUC按负例数加权必须还原原全池高值AUC。
3. 固定检查前8、16、32、64的命中、recall、precision，首个和中位高值排名，以及前16分类。
   主批量保持16，其他截断不计作新标签预算实验。
4. XGB固定原加法与beta=1：00=旧均值+旧sigma，10=新均值+旧sigma，
   01=旧均值+新sigma，11=新均值+新sigma。只新增中间两种分支，共120条；两端必须重建原E。
   RF的E只依赖sigma，因此不制造均值替换无效的重复四组；原RF的G/E证据仍在上一轮结果中。

混合分支使用同一标签尺度上的原始预测数值，未校准或搜索权重。这是固定保存输出的计算反事实，
不代表训练出了对应新模型、可部署方法或识别了生物因果机制；未增加matched-random矩阵。

每assay/model按共享seed槽重采样，保留32/64嵌套：20,000次、99.375%描述性百分位区间。
不把20状态当作20个独立生物样本，不合并assay作推广CI，无应用delta、无等价检验。
本轮前沿使用PCG64种子10800/10801，混合分支10901；上一轮使用10600/10601。
端点和点估计精确相同，区间末位可能因Monte Carlo流不同而变化，不据此选择报告版本。
多个诊断未建立整体家族错误率保证，不把名义区间当作新的确认性显著性判据。
