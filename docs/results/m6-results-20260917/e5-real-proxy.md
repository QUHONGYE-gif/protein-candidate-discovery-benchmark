# 历史单元的有限科学声明

本文件保留该完成单元的声明，属于 L1 开发期结果。文中“尚未完成”的后续工作描述以本结果包总览为准，不回写该单元历史范围。独立咨询仅为 advisory，不替代指定协作者审批。

# E5 proposed bounded claim — v1

本结论限于预先指定的四个既有 ProteinGym 开发池（每池256候选）、同一 ESM1v_single/+1 代理、五个配对初始化 seed、原始 RF 与 A 评分、LF成本1/4、HF100、总预算6400。140条完整唯一轨迹对应160逻辑条目；20条HF-only明确复用，seed不作为独立assay。

1. 真实zero-shot信息源可以在某些任务与策略组合产生发现增益，但本实验没有建立跨任务稳定收益。BLAT硬筛选在两个LF价位的最终top1%召回平均均比HF-only高40个百分点（3胜2平0负）；固定比例高20个百分点（2胜3平）。预设方向规则要求至少4个严格同号配对且均值差至少5个百分点，因此这些都仍记inconclusive；该标签不否认已观察的正均值。CAPSD硬筛选分别低20/26.7个百分点（1胜4负），达到预设negative标准；所有24项主比较0positive/2negative/4unstable/18inconclusive，不是显著性或等效性判定。

2. 原A成本感知策略在四任务、两成本的八项比较中，没有正的平均最终召回差；六项inconclusive、两项unstable。结果不支持该具体策略在本面板有稳健优势，也不证明所有信息采购、所有信息价值定义、全部真实代理无效。E5保持A，没有检验B在真实代理下的效果。

3. 硬筛选存在可直接由候选集合核查的限制：LF前25%分别保留BLAT/CAPSD/GFP/SPG1的3/1/1/0个主高价值候选（各池共3个）。SPG1过滤后不能新增发现这3个目标；总体可达召回还须加上初始16HF已经发现的目标。该集合限制解释了哪些目标对这一硬筛选规则不可达，但不是移除筛选的干预效应，也不构成四任务统一根因；全局相关性/上尾质量与收益的关系仅为描述性。

4. 成本与发现终点要分别评价。BLAT硬筛选在两价位均有5/5达到recall>=0.5，HF-only为2/5；只在双方均达标的2对里，平均相对成本节省从LF1的+18.6%变为LF4的−11.8%。该条件均值受删失选择影响，不能称整体平均节省；费用只是预设购买单位，不是真实货币或湿实验节省。

5. 20条HF控制本轮从头拟合，并与原E4选点事件、三个评分向量、state hash和共同评估字段精确相同（新文件仅增加1600检查点）。真实LF替换后的政策变化可与原合成C0/C3作描述性比较，但代理替换同时改变全局/上尾关联、数值分布和偏差，且真实LF在五seed间固定、原合成LF随seed变化；没有隔离单个机制。保存产物独立公式回放与科学审查，不等于全部MF轨迹由另一实现独立重训。

预算1600/3200/4800是声明总预算6400的同一次轨迹前缀，不是另外三个总预算实验。每池top1%仅3个目标，差值离散且初始化敏感。这里的cross-assay是原面板内比较，不是未见assay/完整landscape泛化。与M5、B评分和共同完整LF的旧消融分别保留证据边界；不能合称已确定M5/M6共同根因或M6唯一原因。

本结果为完成的L1开发期E5证据，可供人工审阅；不是正式Gate B通过、独立协作者批准、论文级确认、冻结证据或公开发布。
